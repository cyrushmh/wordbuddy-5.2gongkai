## 二、wine-sni-bridge · Linux 桌面整合工具

- **性质**：`waliori/wine-sni-bridge` 上游 MIT 许可，~580 行单文件 Python 守护进程。
- **作用**：把 Wine/Windows 系统托盘图标桥接到 Wayland 的 StatusNotifierItem（SNI）协议，根治 KDE `xembedsniproxy` 在 wlroots 系合成器（Sway/Hyprland/dwl）上**抢键盘焦点**的已知问题（`swaywm/sway#7130`）。
- **原理**：认领 `_NET_SYSTEM_TRAY_S0` → 图标窗口嵌入离屏**托管型**容器（`override_redirect=False` + `_NET_WM_WINDOW_TYPE_UTILITY`，永不请求焦点）→ 抽取/裁剪/缩放像素 → 每条 DBus `StatusNotifierItem` 推送 → Waybar 等状态栏。
- **亮点**：图标缓存（按 WM_CLASS）、点击转发、抗状态栏重启、过期图标清理、字节序（`--byte-order native/network`）。
- **应用**：镜像进 `windows-internals-toolkit/tools/wine-sni-bridge/`（`.py` + `README.md` + systemd 用户服务），作为「Windows 兼容层 / Wayland 桌面整合」互补工具。提交 `be733f3`+`0066231`，推到新分支 `wine-sni-bridge`。

### 跨语言注记 · CangjieHelloWorld
仓颉是 HarmonyOS NEXT 自研原生语言，其 ArkUI 写法与 ArkTS **同构**（同一套声明式 UI 运行时）：
```cangjie
@Entry
@Component
class EntryView {
    @State var message: String = "Hello Cangjie"
    func build() {
        Row { Column {
            Button(message).onClick { evt => AppLog.info("Hello Cangjie") }
                .fontSize(40).height(80)
        }.width(100.percent) }.height(100.percent)
    }
}
```
这印证用户判断：**ArkTS 与仓颉是「一套 ArkUI 字节码」的两种源语言**——所以组网无障碍（分布式 KV）能跨硬件跑，
底层同样是「源码→Ark 字节码」的归一；但仓颉源码不能直接 import 进 ArkTS 工程，只可抽概念。本项目守 ArkTS NEXT。
