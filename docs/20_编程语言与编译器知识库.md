# 二十、编程语言与编译器知识库（v0.6.53, #379）

## 一、范围与诚实边界

用户要求：「引入从 2008 年到现在的所有编程语言和编译语言及其他计算机类的，不管国内外还是古今中外，都要」。

**诚实边界**：2008 至今新出现的编程语言数以千计（含大量小众/实验/esolang），逐条核验事实并结构化入库既不现实、也易臆造。本知识库采取**精选代表性集合**策略：

- **主体**：2008–2026 窗口内首现的语言（**72 条**）——覆盖主流（Rust/Go/Kotlin/Swift/Julia/TypeScript/Elixir/Zig…）与小众/实验（Hare/Bend/Carbon/Mojo/Gleam/Roc/Odin/Noir/Cairo/Wa/Go+/仓颉/文言/ArkTS/Futhark/Pony/Verse/Unison…）；
- **古今锚点**（**89 条**，`in_window=false`）：Fortran/Lisp/ALGOL/C/Pascal/Java/Python/JavaScript/Haskell/Scala/Simula/Eiffel/Ada/APL/Forth/Erlang/OCaml… 等影响深远的历史语言，构成「古今」维度；
- **国内外**：国外 143、国际 8、**国内 10**（易语言、文言、仓颉、凹语言、Go+、木兰、习语言、周蟒、汉语编程、ArkTS）——构成「国内外」维度；
- **其他计算机类**：除通用编程语言外，含查询(SQL/GraphQL/SPARQL/Cypher/XPath/Datalog)、标记(HTML/CSS/Markdown/XSLT)、数据(JSON/YAML/TOML/Protobuf/Avro/FlatBuffers/Cap'n Proto)、配置(Nix/HCL/Jsonnet/Dhall/CUE/Pkl/Starlark/Make/OpenAPI)、Shell(bash)、IR(WebAssembly)、**硬件描述(Verilog/VHDL)**、排版(LaTeX)、记号(正则/BNF/PostScript)、验证(F*/Idris/Lean/Coq/Agda/Isabelle/Dafny/Whiley) 等；
- **esolang（深奥语言）**：Brainfuck/Befunge/INTERCAL/Malbolge/Piet/Whitespace/LOLCODE/Unlambda/Shakespeare/Chef（10 条）与中文文言编程。

**元数据纪律**：仅结构化描述（首现年/范式/类型系统/实现/设计者/来源/状态/标准/分类/备注），**不复制任何教材或文档原文**；年份、类型系统、实现为公开事实，存疑项在条目 `needs_verify` 标注（共 **12 条**，如 Carbon/Mojo/木兰/仓颉/ArkTS/Coq/Verse/Unison/汇编年份等以官网为准）。新增条目只需往 `languages` 数组追加，schema 不变——**可扩展、非一次性普查**。

**当前口径（v0.6.55）**：总 **161** 条；窗口内 72 / 窗口外 89；分类 compiled 73、interpreted 38、config 10、transpiled 8、query 6、data 6、jit 3、notation 3、verification 5、markup 4、hdl 2、ir 1、shell 1、typesetting 1。

## 二、数据层

`data/langs_docs.json`：

```json
{
  "_meta": { "title": "...", "scope": "...", "window": "2008-2026",
             "entry_count": 84, "honesty_note": "...",
             "categories": [...], "origin_values": ["国外","国内","国际"] },
  "languages": [ { "id": "rust", "name": "Rust", "name_zh": "Rust",
                  "first_year": 2010, "first_release": "...", "paradigms": [...],
                  "type_system": "...", "implementation": "...", "designer": "...",
                  "origin": "国外", "region": "...", "status": "...",
                  "standard": "...", "category": "compiled", "in_window": true,
                  "notes": "...", "needs_verify": [...] }, ... ]
}
```

必填字段见 `research/langs/validate_langs.py` 的 `REQUIRED`。

## 三、校验（防漂移）

`research/langs/validate_langs.py` 是可复现/防漂移守卫：

- 默认运行：回填 `_meta.entry_count` 使其与 `languages` 实际长度一致，再校验其余 schema；
- `--check`：仅校验，不一致（字段缺失 / category·origin 越界 / `in_window` 与 `first_year` 矛盾 / `needs_verify` 非列表 / `entry_count` 漂移）即非零退出，用于 CI。

核心不变量：**`in_window == (2008 <= first_year <= 2026)`**——任何条目若改了首现年却忘改 `in_window`，校验即抓获。

```
python research/langs/validate_langs.py --check   # CI 防漂移
```

## 四、native 只读层

`native/langs.py`（惰性加载 data/langs_docs.json，与 rfc_catalog/recert 同口径）：

| 函数 | 返回 |
|---|---|
| `info()` | `_meta`（标题/范围/窗口/诚实说明/枚举） |
| `stats()` | 总数、窗口内/外、待核实数、按分类/来源/状态计数 |
| `all_langs()` | 全量条目 |
| `get(id)` | 单条（不区分大小写） |
| `search(q)` | 名称/中文名/设计者/范式/备注子串检索（按年降序） |
| `by_category(cat)` | 按分类（compiled/interpreted/jit/transpiled/query/markup/data/config/shell/ir/typesetting/notation/verification） |
| `by_origin(o)` | 按来源（国外/国内/国际） |
| `window(only=True)` | 窗口内语言（按年降序） |
| `paradigms()` | 范式分布（按数量降序） |
| `needs_verify()` | 存疑条目集中列出 |

## 五、CLI（子命令 `langref`）

> 注意：`langs` 已被「语言运行时探测」子系统占用，知识库子命令取名 `langref`。

```
sysweeper langref                      # overview：库速览 + 诚实说明
sysweeper langref stats               # 总数/窗口内/分类/来源统计
sysweeper langref window              # 2008–2026 窗口内 49 条（首现年降序）
sysweeper langref search <词>         # 检索（如 rust / 华为 / 函数式）
sysweeper langref show <id>           # 单条详情（如 cangjie / rust）
sysweeper langref category <分类>     # 按分类（如 ir → WebAssembly）
sysweeper langref origin <来源>       # 按来源（国内/国外/国际）
sysweeper langref paradigms           # 范式分布
sysweeper langref verify              # 待核实条目（needs_verify）
```

标杆核验：Rust→2010/compiled/国外；仓颉→2024/国内/compiled（窗口内，needs_verify）；WebAssembly→ir/国际；国内集合含{wenyan,cangjie,wa,goplus,mulan,xlang,zhpy,easylanguage}。

## 六、GUI 面板（v0.6.54）

与 `#377` 的 RFC 面板同款做法，`gui.py` 新增 `show_langref()`，底部按钮栏加「编程语言库」入口，
**只读三页**（`ttk.Notebook`），与 CLI `langref` 同数据层、同口径：

- **窗口内(2008–2026)**：72 条按首现年降序列表，点选右侧显示单条详情（首现年/发布沿革/范式/类型系统/实现/设计者/来源/状态/标准/备注）；
- **分类/来源**：分类下拉（compiled/jit/transpiled/…）+ 来源下拉（国外/国内/国际），「按分类列出」「按来源列出」填充成员列表，点选看详情；
- **检索/待核实**：关键词检索（另有「示例 rust」按钮），以及「待核实」按钮直接列出 12 条 `needs_verify` 条目——**存疑项在详情里以「⚠ 待核实：」原样标出**，不做臆造补全。

> 详情里「首现年」与「发布沿革」分两行展示：`first_release` 字段本身已含年份与沿革，
> 合并成 `首现：1993（1993…）` 会出现年份重复，故分开打印。

无图形环境（SSH/容器/CI）时 `gui.py` 整体优雅降级，面板不参与无头执行。
