# 23 · 「道枢」治理层概念系统（v0.6.58）

以仓库 **wordbuddy-github 为主目录（概念系统）** 新增的**治理层**：用经典思想为既有
概念系统提供指导理念与校验边界，并把理念**翻译成可审计的工程原则**，桥接到
`plang`（编程语言）、`netsys`（网络组网）、`langref`（语言知识库）。

## 1. 四层结构（用户指定口径）

| 层 | 角色 | 依据 | 内容 |
|---|---|---|---|
| 前置指导思想 | `pre` | 《太上玄门早坛功课经》 | **44 节**：净坛 → 启请 → 净心/净口/净身 → 安镇 → 通诚 → 卫身 → 开经 → 诵经(常清静经/护命/禳灾/心印) → 礼诰 → 忏愿 → 结行 |
| 中心指导理念 | `center` | 《道德经》 | **81 章**：道经 1–37 / 德经 38–81，每章登记章旨 + 节旨 + 归属治理原则 |
| 中间二级思想 | `middle` (tier 2) | 《般若波罗蜜多心经》+《论语》 | 心经 5 段（破相：照见→色空不二→空相→无所得→咒）+ 论语 20 篇（立礼：学而…尧曰），每段/篇带工程落法 |
| 后置指导思想 | `post` | 《太上玄门晚坛功课经》 | **29 节**：净坛 → 启请 → 开经 → 诵经(救苦/升天得道/解冤拔罪) → 礼诰 → 济度 → 立愿(报恩/十二愿) → 结行 |

读写侧落法：**早坛=开工前的校准面**（环境只读盘点、工具链检测、开关确认、风险提示），
**晚坛=收工前的复盘面**（结果对账、失败如实善后、回写状态、报告与遗留交代）。

## 2. 治理原则：15 条（由理念落成，可审计）

每条原则 = 义理纲宗 + 工程落法 + 经典依据 + 可查证的桥接目标：

| 原则 | 义理核心 | 工程落法 |
|---|---|---|
| 道法自然 | 依环境本性，不强加 | 按真实目标环境归类；无工具链标「未实测」，不臆造 |
| 无为 | 不做无谓干预 | 写操作必须 opt-in，只读是默认值 |
| 治大国若烹小鲜 | 少扰动、不越权 | 变更小步可回滚；不替用户/模块做决定 |
| 守中 | 数穷不如守中 | 阈值/档位/并发取中位默认，留上下界 |
| 上善若水 | 柔下而不争 | 兼容层承接脏活，主链路保持简单 |
| 柔弱胜刚强 | 至柔驰骋至坚 | 失败给可执行退路；重试有上限与退避 |
| 不争 | 不争而莫能争 | 资源共享走队列配额，不抢占 |
| 知足知止 | 知止不殆 | 一切增长有界（超时/TTL/队列/日志） |
| 见素抱朴 | 少私寡欲 | 能复用标准/模块就不新造，最少依赖 |
| 反者道之动 | 有无相生 | 任何变更有反向路径（回滚）；指标成对呈现 |
| 图难于其易 | 作于细、生于易 | 先跑通最小能力面（8 面能力契约）再扩张 |
| 知不知上 | 知之为知之 | 存疑标 `needs_verify`，未实测原样标出 |
| 信言不美 | 不美言不信 | 失败如实报失败及原因，不用漂亮话掩盖 |
| 无之以为用 | 留白即能力 | 接口/扩展点保留可替换空位 |
| 生而不有 | 长而不宰 | 格式开放可导出，不锁定用户 |

## 3. 桥接：31 条边到既有概念系统（无悬空）

| 目标系统 | 边数 | 代表 |
|---|---|---|
| `plang` | 6 | `arch:*`/`model:*` 归类依据、`probe` 8 面契约、`needs_verify` 诚实约定 |
| `netsys` | 22 | `module:network`（唯一写模块 opt-in）、`module:reshare`、`module:distcompute`（有界）、`layer:*` 真实落位 |
| `langref` | 3 | `needs_verify` 字段、二级域由易入难 |

构建期强制校验：每条桥接目标必须在 `data/concepts/` 下的 `plang_taxonomy.json` /
`netsys_taxonomy.json` / `langs_docs.json` 中真实存在，否则构建失败。

## 4. 用法

```bash
# CLI（只读不联网）
python3 -m sysweeper daoxue                 # 四层速览
python3 -m sysweeper daoxue center 25       # 道德经第 25 章（章旨/节旨/原则/落法）
python3 -m sysweeper daoxue pre | post 结行 # 早坛全文 / 晚坛·结行 节次
python3 -m sysweeper daoxue middle          # 心经 5 段 + 论语 20 篇
python3 -m sysweeper daoxue principles wuwei  # 单条治理原则 + 章 + 桥接
python3 -m sysweeper daoxue bridge netsys   # 理念 → netsys 的桥接边
python3 -m sysweeper daoxue apply plang     # plang 适用的治理原则
python3 -m sysweeper daoxue search 水        # 跨层检索
python3 -m sysweeper daoxue verify          # 诚实边界（需核实项）
python3 -m sysweeper daoxue stats           # 规模统计

# 构建与防漂移（源文本为用户上传 PDF 经 pdftotext 提取，不入库）
python3 research/daoxue/build_daoxue.py --check

# GUI：底部「道枢治理观」按钮（三页：道德经中心 / 早坛晚坛 / 原则·桥接·检索）
```

## 5. 诚实边界（needs_verify，不臆造）

- 《心经》《论语》用户未附原典文本，按通行本节次/篇义登记纲宗，标 `needs_verify`。
- 上传《道德经》PDF 为**译文版**（只含白话解释），故只登记章旨与解释首句，
  不录古文原文（原文以通行本为准）。
- 不复制经典全文：data 层只存结构化元数据；源文本不入库（`research/daoxue/sources/`
  已被 gitignore），以 sha256 在 JSON `sources` 段留痕。
