# 24 · 量子理念概念系统（v0.6.59）

以仓库 **wordbuddy-github 为主目录（概念系统）** 新增的**量子理念层**：把量子计算的
公开理念按七域结构化登记（只读、不联网），桥接到 `netsys`（网络组网）、`daoxue`
（治理原则）、`plang`（编程语言），供 TLS/PQC 等既有模块做**抗量子口径**的理念参照。

## 1. 七域结构（54 个概念）

| 域 | 定位 | 概念数 | 内容 |
|---|---|---|---|
| `state` | 量子态表示 | 6 | 信息载体：量子比特、叠加、纠缠、混态描述与测量公设 |
| `circuit` | 量子门与线路 | 6 | 操作原语：Pauli/H·S·T/旋转门/纠缠门/通用门集合与线路模型 |
| `algorithm` | 量子算法 | 10 | 问题类与加速来源：相位/振幅放大、变分法、线性系统 |
| `hardware` | 硬件平台 | 8 | 物理实现路线：超导/离子阱/中性原子/光子/硅自旋/退火，及现阶段定位 |
| `error` | 纠错与噪声 | 7 | 从 NISQ 噪声缓解到容错量子计算的码与阈值 |
| `network` | 量子网络 | 8 | 量子密钥分发、中继与量子互联网；含经典后量子密码（PQC） |
| `toolchain` | 标准·语言·工具链 | 9 | OpenQASM 3、QIR、词汇标准、QKD 网络标准与开源 SDK 生态 |

## 2. 标准登记册：7 条（逐条核实状态）

| 标准 | 类别 | 状态 | 依据 |
|---|---|---|---|
| ISO/IEC 4879:2024 | 词汇标准 | verified | iso.org（2024-06 发布；我国牵头制定的全球首个量子计算领域国际标准） |
| OpenQASM 3.0 | 语言规约 | verified | openqasm.com 现行 live specification（2026-07 仍为现行版） |
| QIR | 中间表示规约 | verified | QIR Alliance qir-spec（v2.0 用 opaque pointer，需 LLVM 16+） |
| ITU-T Y.3800 | ITU-T 建议书 | verified | itu.int（Y.3800-2019 支持 QKD 的网络概述） |
| ETSI GS QKD 014 | QKD 接口 | verified | ETSI GS QKD 系列（014 定义 QKD 系统向应用交付密钥的接口） |
| FIPS 203/204/205 | PQC 标准 | verified | NIST（2024-08 发布：ML-KEM、ML-DSA、SLH-DSA） |
| IEEE 7130 | 术语标准 | **needs_verify** | P7130 项目 2017 年获批；正式标准号发布状态本轮未核实 |

## 3. 桥接：18 条边到既有概念系统（无悬空）

| 目标系统 | 边数 | 代表 |
|---|---|---|
| `netsys` | 10 | `module:tls13`（Grover 使对称密钥等效安全位束约减半，套件强度须按抗量子口径折算）、`module:cert`、`module:network` |
| `plang` | 5 | `lang:rust`（QKD/PQC 参考实现生态）、`lang:python`、`lang:csharp` |
| `daoxue` | 3 | `principle:zhi-bu-zhi`（知不知上：存疑标准标 needs_verify）、`principle:tu-nan-yu-yi` |

构建期强制校验：每条桥接目标必须在 `netsys_taxonomy.json` / `plang_taxonomy.json` /
`daoxue_taxonomy.json` 中真实存在，否则构建失败。

## 4. 用法

```bash
# CLI（只读不联网）
python3 -m sysweeper quantum                 # 七域速览
python3 -m sysweeper quantum state           # 某域全部概念
python3 -m sysweeper quantum of grover       # 单概念（纲宗/详述/桥接）
python3 -m sysweeper quantum standards       # 7 条标准登记册（核实状态）
python3 -m sysweeper quantum bridge netsys   # 量子理念 → netsys 的桥接边
python3 -m sysweeper quantum search 纠缠      # 跨域检索
python3 -m sysweeper quantum verify          # 诚实边界（需核实项）
python3 -m sysweeper quantum stats           # 规模统计

# 构建与防漂移
python3 research/quantum/build_quantum.py --check

# GUI：底部「量子理念」按钮（四页：七域分类轴 / 标准登记册 / 桥接 / 检索·待核实）
```

## 5. 诚实边界（needs_verify，不臆造）

- **不含量子硬件探针、不接入量子设备、不执行量子线路**：本仓库为经典系统工程
  工具箱，本系统只做理念与标准登记。
- 算法结论（如 QAOA 优势）按文献现状登记，**不夸大为定论**；量子体积（QV）等
  基准数值随硬件代际变化，只登记方法论不登记数字。
- 7 条标准中 6 条本轮联网核实（带 source）；IEEE 7130 立项信息来自公开报道，
  正式标准号/发布状态未核实，登记待验证（`needs_verify` 3 条：标准 1 + 概念 2）。
- **红线**：概念登记不构成威胁评估或采购建议；PQC/QKD 相关动作只给指引不代改
  （承接 chrono/tls13 既有红线）。
