# 25 · 编译与工具链概念系统（v0.6.59）

以仓库 **wordbuddy-github 为主目录（概念系统）** 新增的**编译与工具链层**：把
「公开的计算机编程语言和编译需要」按五轴结构化登记（只读、不联网），桥接到
`plang`（编程语言概念系统）、`llvm`（工具与目标三元组矩阵，数据层
`data/llvm_docs.json`）、`daoxue`（治理原则）。

## 1. 五轴结构（50 个概念）

| 轴 | 定位 | 概念数 | 内容 |
|---|---|---|---|
| `pipeline` | 编译流水线 | 8 | 源码→产物的阶段链：前端（词法/语法/语义）→中端（IR 优化）→后端（指令选择/寄存器分配）→汇编→链接 |
| `toolchain` | 工具链家族 | 10 | 成套工具的组合：GNU / LLVM / MSVC / MinGW-w64 / 交叉工具链… |
| `build` | 构建系统 | 8 | 驱动编译与打包的编排层：make / cmake / ninja / bazel / 构建缓存 / 可复现构建 |
| `artifact` | 目标产物 | 8 | 产物形态：库/可执行/字节码/wasm/IR/安装包/镜像 |
| `lang-need` | 语言编译需要 | 16 | 每种语言的驱动工具与产物形态：**15 种实测（带证据）+ 1 条汇总 needs_verify** |

## 2. 语言编译需要：15 种实测 + 146 种汇总待核实

证据口径：仅 `plang` probe **实测通过**（8 面能力契约：字面量/运算/控制流/函数/
数据结构/IO/错误/并发）的 15 种语言逐条登记明细；其余 146 种**汇总为一条
needs_verify**，不逐条臆造工具链形态。

实测 15 种：`python` / `javascript` / `typescript` / `go` / `rust` / `c` /
`cplusplus` / `java` / `ruby` / `perl` / `bash` / `awk` / `tcl` / `fsharp` /
`makefile`（证据取自 `plang_taxonomy.json` 的 `probe_results`）。

## 3. 桥接：41 条边到既有概念系统（无悬空）

| 目标系统 | 边数 | 代表 |
|---|---|---|
| `plang` | 30 | `lang:c`（归宿语言）、`model:ir`（中间表示定位）、`arch:x86-64`/`arch:riscv`（目标架构） |
| `llvm` | 9 | `tool:clang`（本仓库 native/llvm 探针已接入）、`tool:mlir`（多级 IR 代表）、`tool:lld`、`target:x86_64-w64-mingw32`/`target:wasm32-unknown-unknown`（目标三元组） |
| `daoxue` | 2 | `principle:daofa-ziran`（按环境本性选工具链）、`principle:zhi-bu-zhi`（未实测不臆造） |

构建期强制校验：plang 目标按 `lang:`/`model:`/`arch:` 前缀在 `plang_taxonomy.json`
核对存在；llvm 目标按 `tool:`/`target:` 前缀在 `llvm_docs.json` 的
`tools`/`targets` 核对；daoxue 目标按 `principle:` 在 `daoxue_taxonomy.json`
核对——任一悬空构建失败。

## 4. 用法

```bash
# CLI（只读不联网）
python3 -m sysweeper comp                     # 五轴速览
python3 -m sysweeper comp toolchain           # 工具链家族轴全部概念
python3 -m sysweeper comp of llvm-toolchain   # 单概念（含桥接边）
python3 -m sysweeper comp needs               # 15 种实测语言的编译需要汇总
python3 -m sysweeper comp need rust           # 单语言编译需要（驱动工具/产物/证据）
python3 -m sysweeper comp bridge plang        # 编译概念 → plang 的桥接边
python3 -m sysweeper comp search 交叉编译      # 跨轴检索
python3 -m sysweeper comp verify              # 诚实边界（146 种汇总待核实）
python3 -m sysweeper comp stats               # 规模统计

# 构建与防漂移
python3 research/comp/build_comp.py --check

# GUI：底部「编译工具链」按钮（四页：五轴分类轴 / 语言编译需要 / 桥接 / 检索·待核实）
```

## 5. 诚实边界与红线

- **本概念系统只读登记，不驱动任何真实编译**——编译动作属各工具链自身
  （`llvm` 子系统的 native 探针只读检测已安装工具链，不发起编译）。
- 语言编译需要明细仅覆盖 15 种实测语言；其余 146 种语言的工具链形态**没有
  逐条核实，汇总标注 needs_verify**（`need-rest-unverified`），按语言逐个补
  证据后再拆分登记。
- `pipeline`/`build` 等轴登记**通用阶段与编排层概念**，不代表本仓库实现了全部
  构建系统对接。

## 7. 遗留与后续

- 146 种语言的编译需要可按 `plang` probe 扩容逐步拆分：每补一种语言的实测证据，
  即从汇总条目拆出一条明细。
- llvm 目标三元组矩阵后续如扩充（`llvm_docs.json` 增加 targets），comp 桥接可
  同步新增 `target:*` 边，`--check` 会校验无悬空。
- 可增加「产物形态 → 本仓库打包器（tools/syspkg.py）」的桥接边。
