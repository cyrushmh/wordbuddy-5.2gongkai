# 29 · 百工匠作概念系统与全语言完善优化（v0.6.61）

> 以仓库 `wordbuddy-github` 为主目录。本文登记第八个概念系统 `baigong`（百工），
> 以及 161 条语言的全量六字段补全与国际化/本地化收尾。只读不联网，
> 不复制经典全文，不宣称任何未实测的工程能力。

## 1. 立意：三场景的理念指导

docs/21–28 已建立七个概念系统：`plang`（编程语言）、`netsys`（网络组网）、
`daoxue`（道枢治理层，中心《道德经》）、`quantum`（量子理念）、`comp`
（编译工具链）、`apilab`（接口 API）、`zhuangzi`（南华用户端）。本系统补上
第八块：**工程怎么做具体结构**（墨子、公输般、公孙策、鲁班，可扩大为三教九流）。

用户点名的三个工程场景，落成 `scenes` 轴三条概念：

| 场景 | 概念 | 工程落法 |
| --- | --- | --- |
| 具体无解 | `scene-wujie` | 悬置降级：当前无解不硬解，登记 needs_verify、给出可验证的部分 |
| 暂时不允许 | `scene-buyunxu` | 守御 opt-in：不允许的事走显式白名单入口，最小攻击面 |
| 构建程序具体结构 | `scene-jiegou` | 绳墨与九设九距：先定检（绳墨）再兵推（九设九距） |

## 5. 语言完善：161 条六字段补全（诚实口径分级）

`research/plang/lang_enrich.py`（161 语言人工五字段：范式/类型系统/内存管理/
一句话定位/工程落法）经 `build_plang.py` 合并进 `plang_taxonomy.json`，
`first_appeared` 不重复登记、构建时取数据层 `first_year`（单一事实来源）。
CLI `plang of <id>` 输出概念卡片。**工程落法三条红线**：

1. probe 实测通过的 15 种语言标「probe 实测通过」并给具体落法（rust 落
   cargo build/test+clippy；python 落 -m py_compile 等）；
2. 其余 146 种只登记工具链名称，**不宣称可编译**（如 mulan 标注「已停更且卷入
   复用争议，不建议引入」）；
3. 非执行类（HTML 等宿主工具解释）与 esolang（brainfuck 等玩具/实验）如实标注。

构建 `--check` 新增三类校验：陈旧补全键报错、六字段非空逐条查、probe 口径一致
性（`claims != passed` 报错）。

## 7. 入口与用法

```bash
# 百工概念系统（八系统同构，只读不联网）
python -m sysweeper baigong overview          # 四轴速览 + 实测面
python -m sysweeper baigong core              # 核心理念五偶
python -m sysweeper baigong craft             # 七条匠作原则
python -m sysweeper baigong schools           # 三教九流 12 条
python -m sysweeper baigong scenes            # 三工程场景
python -m sysweeper baigong concept mozi      # 单条概念
python -m sysweeper baigong principles mozi   # 某理念对应的原则
python -m sysweeper baigong bridge comp       # 桥接边（可按系统过滤）
python -m sysweeper baigong userface          # 用户端面 + 语言面实测
python -m sysweeper baigong verify            # needs_verify 挂牌

# 语言完善（v0.6.61 六字段）
python -m sysweeper plang of rust             # 概念卡片（六字段）
python -m sysweeper plang --locale en of lua   # 壳层英译、数据层中文

# 构建层防漂移（八个 taxonomy 全部通过）
python research/baigong/build_baigong.py --check
```

GUI：底部按钮区新增「百工理念」（`show_baigong`，四轴三页 + 实测面页）；
「概念系统中心」窗口八系统总览 + 跨系统检索。

## 8. 诚实边界与红线

1. **不复制经典全文**：只登记理念 gist 与工程落法；用户未上传《墨子》原典，
   引文按通行本登记并统一挂 `needs_verify`（4 项：引文未核对 / 公输般即鲁班
   一名两译 / 公孙策系文学形象 / 三教九流工程映射），不逐字臆造原文。
2. **只读登记，不驱动任何真实施工**：三场景落法是理念的工程翻译，不代替真实
   施工决策；本系统不执行任何写操作。
3. **语言工程落法分级如实**：probe 实测通过（15 种）/ 未实测只登记工具链
   （146 种）/ 非执行类与 esolang 单独口径，绝不以「可编译」含糊带过。
4. **测试护航**：`tests/test_baigong.py` 9 项（四轴 27 概念、五偶、七原则、
   三教九流、三场景、只读 API、43 桥接无悬空、user_face 与 argparse/gui/
   plang/comp 交叉一致、needs_verify 挂牌、`--check`）；概念系统中心口径
   同步七→八系统。
