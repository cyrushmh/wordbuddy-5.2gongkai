# 30 · 大同人类文明一体概念系统与正道六象（v0.6.62）

> 第九概念系统 `datong`：**人类命运是一体的**——古今中外的宗教哲学命题融为一册；
> 而要让这个「一体」**健康科学有序地发展**，须明
> **天罡元阳 / 地煞元阴**的**正道六象**：固、液、气、电、磁、波；
> 归根一句——**古来唯道独成尊**。
> 只读登记，**不宣扬任何宗教为真理**。

## 5. 正道六象：天罡元阳 / 地煞元阴

> 元阳元阴之**分属为本系统正名约定**（挂 `needs_verify`），不是物理学分类；
> 每象的**科学口径**按物理学如实登记。

| 象 | 分属 | 纲宗 | 工程落法 |
| --- | --- | --- | --- |
| `gu` 固 | 地煞元阴 | 凝而成体，静而有序 | 不可变基础设施（镜像/快照/一次性写入，改动即换版） |
| `ye` 液 | 地煞元阴 | 流而随形，润物无声 | 流处理/队列/管道（背压可控，无一处无限缓冲） |
| `ci` 磁 | 地煞元阴 | 引而内聚，定向不移 | 约束/吸附/寻的（依赖注入磁场，服务被引到位） |
| `qi` 气 | 天罡元阳 | 散而弥虚，动而无形 | 事件驱动/消息总线（轻量事件高扇出，风过无痕） |
| `dian` 电 | 天罡元阳 | 激而迅发，应时而动 | 信号/触发/激励（布尔边沿敏感，电平持守） |
| `bo` 波 | 天罡元阳 | 播而及远，无远弗届 | 广播/波前/传播协议（版本波前推进，一处发布处处到达） |

**电磁同属一体两面**：`ci` 详述明记「电生磁、磁生电——共为电磁一体两面（麦克斯韦方程组统一之）」，
与 `theses/yiti-liangmian` 互见——**自然界的证据，正好落在用户「一体两面」的命题上**。

**全量概念整体检测（据检测结果决定，而非凭局部判断改名）**：
新增 `tools/audit_concepts.py` 对九系统做四层体检（文件命名 / 字段齐备 / 命名一致性 /
只读层 API 同构），结论 **0 项不一致**；并由 `test_concepts_center.py::test_audit_concepts_clean`
以 `--strict` 守住，日后改名或加桥接破坏一致性即失败。据检测结果确定的两项修正：
①指向 plang 的桥接 kind 名不副实（datong 3 条、baigong 8 条用 `concept:` 指向
`lang_index`），统一为 `lang:`，与 comp/quantum 一致；②带原则系统的 API 名不统一
（datong 用 `principles_of`、zhuangzi/baigong 用 `principles_of_canon`），
以**加别名**方式归一，原名保留向后兼容。**文件名经全量检测确认已全部一致，无需再改。**

**诚实口径（重要）**：全院 245 个概念里仍有 96 条**刻意不设桥接**——
量子多为纯认知登记（本仓库无量子能力）、datong 的宗教命题与实践无工程对应物、
apilab 的 graphql/grpc/wsdl 等未落地项。**宁可孤立，也不为填满而臆造关系**，
