## 1. mingw-w64：Windows 架构交叉工具链（本次安装核心）

「wming」按 mingw-w64 全套安装，可在 Linux 上直接构建 Windows 原生 PE 二进制，
并用 wine 9.0 实跑验证，形成「交叉编译 → 本机仿真运行」闭环。

### 1.1 编译器矩阵（双架构 × posix/win32 双线程模型）

| 目标 | 三元组 | gcc/g++ | 线程模型 |
|---|---|---|---|
| Windows x64 | `x86_64-w64-mingw32` | GCC 13 | posix / win32（update-alternatives 切换，当前 win32） |
| Windows x86 | `i686-w64-mingw32` | GCC 13 | posix / win32（同上） |

辅助工具：`gendef`（DLL→.def）、`genidl`、`genpeimg`、`mingw-genlib`、
`{x86_64,i686}-w64-mingw32-widl`（IDL 编译器）、`{x86_64,i686}-w64-mingw32-pkg-config`、
`gdb-mingw-w64`（交叉调试 Windows 二进制）。

### 1.2 编译实证（/tmp/mingwdemo，7 种形态全部成功）

| 产物 | 命令要点 | file 判定 |
|---|---|---|
| hello64.exe | `-O2 -static` | PE32+ executable (console) x86-64 |
| hello64dyn.exe | 动态链接（默认） | PE32+ executable (console) x86-64 |
| hello32.exe | i686 `-static` | PE32 executable (console) Intel 80386 |
| demo.dll | `-shared -Wl,--out-implib,libdemo.a` | PE32+ executable (DLL) x86-64 |
| usedll.exe | 链接 libdemo.a 导入 DLL | PE32+ executable (console) x86-64 |
| hi64.exe | `g++ -static`（C++ iostream） | PE32+ executable (console) x86-64 |
| clangwin.exe | `clang --target=x86_64-w64-mingw32` | PE32+ executable (console) x86-64 |

### 1.3 wine 9.0 实跑（全部通过，WINEPREFIX=/tmp/wineprefix）

```
hello64.exe    => Hello from mingw-w64! bits=64
hello64dyn.exe => Hello from mingw-w64! bits=64
hello32.exe    => Hello from mingw-w64! bits=32
usedll.exe     => add(2,3)=5 banner=classics-mingw-dll   ← DLL 导入链路通
hi64.exe       => C++ mingw ok: 64-bit
clangwin.exe   => Hello from mingw-w64! bits=64
```

clang 可直接以 mingw 为目标交叉编译（无需额外 sysroot 参数）。

### 1.4 复现命令

```bash
x86_64-w64-mingw32-gcc -O2 -static -o app.exe app.c   # Windows x64 静态
i686-w64-mingw32-gcc   -O2 -static -o app32.exe app.c # Windows x86 静态
x86_64-w64-mingw32-gcc -shared -o x.dll x.c -Wl,--out-implib,libx.a
WINEPREFIX=/tmp/wp WINEDEBUG=-all wine app.exe        # 本机仿真运行
gendef x.dll                                          # DLL 导出表 → x.def
```

## 4. Firefox 158.0.1（命令行驱动，无需图形界面）

官方 zh-CN tarball 装于 `/opt/firefox`，`/usr/local/bin/firefox` 软链可用：

```bash
firefox --version                                          # Mozilla Firefox 158.0.1
firefox --headless --screenshot /tmp/shot.png --window-size=1024,768 https://example.com
# → /tmp/shot.png：PNG 1024x768 RGBA（实测成功）
firefox --headless --dump-dom https://example.com          # DOM 打印到 stdout
```

容器内软件渲染会打 `[GFX1-]: RenderCompositorSWGL...` 警告（无害）；
`--dump-dom` 偶发无输出时用 `--screenshot` 佐证，或重试。
