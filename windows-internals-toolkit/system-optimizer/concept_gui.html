标准依据 · 色彩 / 视觉 / 开关 / 视觉健康 / 听觉·多感官·光敏（本次完善）

本页配色与主题开关依循以下公开协议标准（对比度以本页双主题变量实测计算）：
· WCAG 2.2 SC 1.4.3：正文 ≥ 4.5:1、大字/UI 边界 ≥ 3:1（实测：dark 正文 13.9:1 · light 14.8:1；dim 5.8/5.5:1；accent 6.3/4.9:1）。
· WCAG 2.2 SC 1.4.11：矩阵热力单元格 / 开关轨道等功能性图形对象边框 ≥ 3:1（用 --line-strong：dark 3.5:1 · light 3.3:1）。
· CSS color-scheme + @media prefers-color-scheme：声明 dark light 并随系统偏好初值，配 <meta name="color-scheme"> 与早期脚本防首屏闪烁。
· WAI-ARIA APG switch：开关用 role="switch" + aria-checked，标签恒定不随状态变，Space/Enter 切换。
· CSS Color L4 oklch() / light-dark()：感知均匀着色（本页核心调色板用 hex 实测达标，oklch 为推荐演进方向）。
· prefers-reduced-motion：流光动画与切换过渡在「减少动态」偏好下停用（前庭安全）。
· WCAG 2.2 SC 1.4.1 用色：信息不单靠颜色传达（红绿色盲/色觉缺陷患病率：北欧裔男性 ≈8%、女性 ≈0.4%）。本页节点用字形（○●◆▽等）+ 文本标签 + 形状区分九系统，非纯色编码。
· WCAG 2.2 SC 1.4.6 增强对比度（AAA）：正文 ≥ 7:1、大字 ≥ 4.5:1——本页双主题已超此线（dark 13.9 / light 14.8），可作高对比基线。
· WCAG 2.2 SC 1.4.4 缩放 / 1.4.10 回流 / 1.4.12 文字间距：低视力/弱视用户需放大(200%)、放大后无二维滚动、可调行高(≥1.5)/字距(≥0.12)。本页为固定 SVG 画布，以浏览器整页缩放放大矢量不丢清晰，但拓扑图属「图形」不重排（WCAG 对 graphics 例外）——如实标注。
· ISO 9241-303:2011 人因（电子视觉显示）：亮度/对比/眩光控制/减少闪烁/字符高度——指导视觉疲劳与舒适度，与本页减动效、高对比、明暗双主题一致。
· IEC 62471 / IEC-TR 62778 蓝光危害（RG0–RG3）：属灯具/显示硬件光生物安全标准（评 400–500nm 蓝光对视网膜），非 Web 内容标准；软件暗色模式仅降低整体像素亮度、间接减蓝光发射，不是「护眼」保证。
· 听觉 / 多感官 / 光敏（生理 · Web 参考层，呼应圆光术「光 + 多感官」主题，不冒充本仓前端职责）：① WCAG 2.2 1.2.x 时基媒体 / 1.4.2 音频控制 / 1.4.7 低·无背景音频：本页（与 report_viewer）是纯静态视觉产物，无 <audio>/<video>、无自动发声，故 1.2.x/1.4.2/1.4.7 暂不适用，留作契约基线（见 docs/61 §八第 6 条）；若未来引入音视频，须按此三节做字幕 / 可暂停音频控制 / 背景音频 ≤20 dB 改造。② McGurk 效应（多感官整合）：视听冲突时感知会被另一通道「劫持」——佐证「多感官」是真实交互通道而非装饰，本页仅视觉输出、不引入跨感官误导信号。③ WCAG 2.2 SC 2.3.1 光敏癫痫（光敏约束）：任何内容 ≤3 闪/秒，或满足一般闪光阈值 20.0 cd/m² / 红色闪光阈值 6.0 cd/m²（PEAT 可实测）；圆光术的辉光 / 呼吸光效设计为 ≤3 闪/秒且随 prefers-reduced-motion 归零（见 docs/61 §四 4.1）。以上三项是「生理 / 医学 / Web 参考层」，仅作设计原则与知识边界澄清，非本仓当前必须实现的 Web 内容职责。

诚实边界：① 散光（astigmatism）研究提示暗背景+亮字更模糊、亮背景更清晰——「深色模式护眼」对此是反例，故本页保留浅色主题为等效选项，不主张暗色「更护眼」。② 青光眼/白内障 → 对比敏感度下降 → 高对比(1.4.3/1.4.6)需求；其医学管理（眼压、角膜/手术）不属 Web 前端标准职责。③ 真「护眼」= 符合 ISO 9241 的亮度/对比/眩光控制 + WCAG 对比度 + 支持缩放 + 减少动效/频闪——皆本页已落地的层。
