## 一、为什么进仓库

本仓库的既有纪律是「测试即契约」：没有验证链的交付物不进门。模拟器交付物与它的
验证链一起归档，任何人克隆后可一键重放：

```
cd research/quantum/simulator
python3 extract_engine.py   # 从 HTML 原位提取引擎（被测代码 = 交付代码，同源保证）
node verify3.mjs            # 16 条：门逐个 / 纠缠 / QFT 与 QFT† / 三处缺失态实证
node verify5.mjs            # 8 条：相变矩阵 P(θ) / trit↔bit 往返 / 无效对 / 3trit→5bit pack / 三进制寄存器
```

## 二、设计决策

| 决策 | 理由 |
|---|---|
| 单文件 HTML、零依赖、可离线 | 交付物本身即完整环境；双击即开，不引 CDN、不建构建链 |
| 复数 = `[re,im]` 二元组，门 = 程序化构造的酉矩阵 | 杜绝手写矩阵笔误（历史上手写 SWAP/Y 各出过一次错，均由程序化构造与断言抓获） |
| `fullGate(U,n,q)` / `permGate(n,f)` / `QFT(n)` | 2×2 门作用于指定位、经典置换门（CNOT/SWAP/X 统一）、QFT 按 ω^{jk}/√N 生成 |
| 引擎由 `extract_engine.py` 从 HTML 正则原位提取 | 验证对象与交付对象逐字节同源，杜绝「测一份交一份」 |
| 2/3/6 三档比特 | 6 qubit = 64 维，是经典模拟可完整穷举展示的极限甜蜜点 |

## 四、阴阳 = 0/1 = 计算基：天罡地煞预置的互根性纠正

用户第⑤轮提醒「天罡地煞就是阴阳，也可以说是二进制」——此前实现（两个独立 GHZ3 的乘积态，
4 项等幅）只表达了「两仪分张」，丢了阴阳**互根**。已更正为互补纠缠：

```
阴阳对缠 = (|罡000·煞111⟩ + |罡111·煞000⟩)/√2 = (|000111⟩ + |111000⟩)/√2
```

天罡组（气液固，q5q4q3）与地煞组（波磁电，q2q1q0）互为每一位的对偶——|000111⟩ 与 |111000⟩
的按位差恰是六位全反（海明距 6），这正是「阳之极即阴」的可计算形式。

同构的诚实表述（文化-数学遗产，非物理声明）：

- 六位二进制全枚举 = 64 个计算基；六爻全排列 = 六十四卦。**组合层同构是硬事实**；
- 莱布尼茨从传教士白晋处见到卦图后发表二进制论文，是否受启发学界有争议，但二进制的
  东方先声与「六爻即六位」的组合同构无需争议；
- **动力学不同构**：卦变规则（错综往复）不是酉演化；64 卦是离散符号，64 维量子态是连续
  复振幅空间。页面与文化层只共享组合结构，不共享变换规则。

## 五、验证结果（本资产自身的历史）

- **抓出并修复 7 个真实 bug**：
  1. `U2.Y` 矩阵带 0.7071 缩放且对角非零（真值 `[[0,−i],[i,0]]`）；
  2. `permGate` 为逆置换方向（仅自反置换侥幸不出错，补循环置换断言）；
  3. 3 比特下「均匀叠加」漏 H(q1)、「GHZ」单条 CNOT 造不出三体纠缠；
  4. SWAP 视图 3 比特下索引越界 + 2 比特中点跳变（重写为对穿滑移）；
  5. cos/sin 无 UI 入口（补三档切换）；
  6. **阴阳对缠漏清 `zero(6)` 自带的 `v[0]`**——实际成为三腿态，被 verify4 断言抓获
     （最大误差 1.0，正是那条漏网的腿）；
  7. 另有 verify3 两条自身断言写错（X 门小端序期望、GHZ3 链序）在首跑时抓获。
- **verify3 16 条全 ✓**：H/X/Y/Z/S/T、Bell、SWAP、QFT(Bell)、QFT†∘QFT=I、GHZ3、均匀叠加；
  三处缺失态实证：QFT(Bell) 第 2 频=0、QFT(GHZ3) 第 4 频=0、QFT(均匀)=纯零频单峰。
- **verify4 7 条全 ✓**：阴阳对缠（互补两腿）、阴阳一体 GHZ6（|000000⟩+|111111⟩，差 63 = 全位对偶）；
  Bell 测量两确定性分支；Born 频率 p(0)=0.5000（10000 次）。
- 另加：`node --check` 整页脚本语法通过；归档副本原地重放两套验证全绿。

## 五·补、相变矩阵与数制导出（第⑥轮指令后追加）

用户第⑥轮指令：「用我们的标准 6 个量子比特作为数字转换逻辑门，也就是六个相变矩阵，
导出三进制和二进制……从三进制到二进制，也就是传统二进制电脑，然后举一反三」。

**数学内核（全部为纯构造，无硬件依赖——按「数学导论推论的量子也是量子」原则成立）**：

| 构件 | 定义 | 事实 |
|---|---|---|
| 相变矩阵 | `P(θ)=diag(1, e^{iθ})`，每 qubit 一枚，共六枚 | θ=π/2 即 S、π 即 Z、3π/2 即 S†（断言同款等价）；90° 步进覆盖二值（0/180）+ 过渡（±90）；120° 步进即三相（0/120/240） |
| 二进制读出 | 6 基态索引即 6 位二进制数 | 6 qubit = 6 bit，与经典寄存器同构（测量即「量子→经典」的导出） |
| 三进制读出 | 6 位 = 3 对；每对 1 trit：00→0 / 01→1 / 10→2 / **11 无效码** | 3 trit = 0..26；余 37 基态为缺失态（可用作校验位）——27+37=64 诚实平分 |
| 三进制→二进制 | ① 定长码（Сетунь 式）每 trit 2 bit；② 紧 pack 码 3 trit 共 5 bit | 硬汇率 1 trit = log₂3 ≈ 1.585 bit；2 trit < 3 bit < 3 trit < 5 bit，无信息无损压缩 |

「举一反三」的用法：同一引擎换读出制式即得不同架构——6 bit 经典寄存器、3 trit 三进制
寄存器（Сетунь）、3 qubit 八卦寄存器（N=3 档）、2×3 bipartition（天罡/地煞）、
1 个 64 级 qudit（张量积重组）——都是同一 64 维酉空间的不同记账法。

**验证5（8 条）**：相变门三种角度与 S/Z/S† 等价；27 组 trit↔bit 逐一往返；无效对 11 检出；
3 trit=26→5 bit 11010；三进制寄存器 27 项等幅 1/√27、余 37 缺失（误差 0.0）。

## 六、诚实边界

1. **经典模拟，非真实 QPU**：2ⁿ 复振幅的内存墙在 ~15 比特处撞墙——这恰是量子优势的物理来源，
   页面不伪装可扩展；6 比特 = 64 维是甜点。经典模拟量子每步 O(2ⁿ)，经典虚拟机模拟经典系统
   为多项式开销——「架构分层」两侧对等，「装进经典寄存器的代价」两侧不对等。
2. **qutrit / qudit 是等价表达**：真实三能级硬件（离子阱）与 d=6 qudit 的能级物理不在模拟内；
   页面以 6 个二元自由度表达「六态」（同为 64 维酉演化，同构不等同）。
3. **文化数术标签**：天罡/地煞作为分组与互根的修辞（阴阳=0/1=计算基是同构）；「电·磁·波·固·液·气」
   六态仅为命名修辞，不声称物理对应。位序约定：q0=电 … q5=气，天罡=元阳（气液固，q5q4q3）、
   地煞=元阴（波磁电，q2q1q0）。
4. **小比特视图降级如实标注**：64 项行波/电压格截断显示前 8 并注明，全量见分量表；不装作看得全。
5. **「量子优势」是复杂度命题**：2019 年 Google 53 qubit 优越性声明后被张量网络等经典优化大幅压缩，
   「现在经典还行」的边界仍在移动；页面与文档均不将任一时刻纪录当时钟。
