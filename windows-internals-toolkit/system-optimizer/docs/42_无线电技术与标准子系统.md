# 42 · 无线电技术与标准子系统 —— 射频面/SDR 工具链只读诊断 + 法规口径 + 组网接入

> 指令原文：「整理无线电技术及标准和代码文档，应用到概念系统组网能力」。
>
> 本档记录三件事：① 把无线电**技术（射频/链路/SDR 工具链）**、**标准（法规/频段）**
> 与**代码（SDR 工具链）** 整理成知识层并落地为只读诊断子系统；② 四入口接线
> （registry / native 子系统清单 / cli / gui）；③ 接入概念系统组网能力（netsys 加
> `radio` 模块 + 四桥，comp 反向桥），不欠账。

## 1. 起点盘点：散点已有，专库没有

盘点发现：本仓**没有 radio data 库**，但相关散点不少——
- `netsys`：`meshnet`（自组网）/ `link_protocols`（ble/802.15.4 链路能力）/ `openwrt`（路由射频）；
- `recert`：`radio-wcet-continuity`（IEEE WCET 无线认证续证，已停办）；
- `rfc_catalog`：4944/6282/7668/8376/8724/7252 等无线/物联网 RFC 已验证存在。

正确做法不是删散点，而是**新建 `radio` 专库把「射频物理面 + 法规口径」结构化**，
并给弱连接系统（comp/apilab）补确凿入边。

## 3. `native/radio.py`：六段只读报告 + 更严红线

- `_load_refs()` 消费 12 条；`RADIO_CHECKS` 六维度（rf_switches / wifi_phys /
  bluetooth_ctl / rf_devices / sdr_toolchain / regulation_kb）每项回链真实 key；
- `WIRELESS_TOOLS` 12 项存在性表（只 `shutil.which` 探测，不启动）；只读辅助走既有
  `common.run` 通道（rfkill/iw/蓝牙控制器/lsusb/lspci 文本过滤）；
- 六报告：`rf_switch_report`（射频开关，不改开关）/ `wifi_phys_report`（Wiphy/regdom，
  不改 regdom/信道/txpower）/ `bluetooth_report`（只 show 不扫描）/ `rf_devices_report`
  （总线枚举，不绑驱动）/ `sdr_toolchain_report`（只 which 不启动）/ `regulation_report`
  （ISM 全表 + 诚实边界）；聚合 `radio_report()` + `capabilities_report()`；
- `_SELF_POSITION` 红线比全项目更严：**绝不驱动任何真实发射**——不改 regdom/信道/
  发射功率、不开 monitor 注入、不解码他人通信内容、不抓包破解未授权网络、不连校外网
  做写；法规结论只引官方源给合规路径，不代办许可；attack 类工具仅登记存在性。

沙箱（Linux/无射频）冒烟如实标 ✗：rfkill/iw/蓝牙/总线全无、SDR 工具链 12 项全无、
regulation 段完整输出——能力不因环境缺失而编造。

## 4. 四入口接线

- `registry.py`：`from .tasks import (...)` 与 `for mod in (...)` 两处加 `radio`；
- `native/__init__.py`：模块说明段加 `radio` 一行 + 导入列表 + `__all__` 加 `"radio"`（v0.6.75 注释）；
- `native/subsystems.py`：`Subsystem("radio","无线电技术与标准（射频/SDR/法规）","网络/射频","radio","radio_report")`；
- `cli.py`：`cmd_radio`（overview/rf/wifi/bluetooth/rf_devices/sdr/regulation/capabilities）+ `radio` 子命令注册；
- `gui.py`：`show_radio` 弹出窗口 + 导航按钮「无线电/射频」。

## 6. 踩坑

- **guidance 补丁不能整机重建**：磁盘 comp_taxonomy.json 的 `bit8-era→daoxue:guidance`
  根环补丁 build 脚本不生成，整机重建会丢。沿用 docs/40/41 教训——手术式同步计数，
  只加边不重建；
- **RFC 验证**：拟用 RFC 先经 `rfc_catalog` 交叉验证存在性再回填标题，4944/6282/7668/
  8376/8724 全部命中；
- **禁执行禁网络不变量**：`native/radio.py` 不得出现 subprocess/os.system/socket 等
  （`shutil.which` 仅探测允许）；测试 `test_no_execute_or_network_in_layer` 守住。
