# 57 · 工具链全景（概念系统 × 子系统编目）

> 本文件是 `sysweeper` 的 **toolchain 子系统**（`v0.6.70`，只读不写）的配套文档。
> 它把本仓「概念系统 × 子系统」里**全部工具链**与**自研工具软件**，按
> **类别 × 目标架构 × 仓库目录** 三维组织，并给出每个工具的**配置逻辑顺序与命令序列**。
>
> 数据真相源：`src/python/sysweeper/data/toolchain_catalog.json`（结构化编目，2026-10-24 本机 `--version` 实采）。
> 只读探测层：`src/python/sysweeper/native/toolchain.py`（5 个只读报告）。
> 任务层：`src/python/sysweeper/tasks/toolchain.py`（4 任务）。
> CLI：`python3 -m sysweeper toolchain [--category <类别>]`；GUI：主面板「工具链全景」。
>
> **#603 补全轮**（宿主实装未编目工具链入册）：类别 7→**10**、宿主工具链 23→**42 条**、
> 仓库工具软件 11→**14 条**、上游新鲜度 needs_action 11→**27 条**（本轮 16 项全部联网核实）；
> 探针层 `HOST_PROBES` 扩至 39 项 + 3 项绝对路径回退，对 catalog 宿主条目 **42/42 全覆盖**。
>
> **红线**（与全工具一致）：toolchain 只**探测与编目**，**绝不安装 / 卸载 / 构建 / 下载**。
> 下文所有 `配置[N]` 与 `命令[N]` 是 **README 性质的逻辑顺序**，给人看的，不是自动执行队列。
