## 二、标准清单与量化阈值

| 标准 | 层级 | 关键阈值 / 要点 |
|------|------|----------------|
| **WCAG 2.2 SC 1.4.1 用色**（A） | Web 内容 | 信息**不单靠颜色**传达；需形状/文本/亮度差等附加区分。色觉缺陷患病率：北欧裔男性 ≈8%、女性 ≈0.4%（protan/deutan 最常见）。 |
| **WCAG 2.2 SC 1.4.3 对比度最小**（AA） | Web 内容 | 正文 ≥4.5:1、大字(≥18pt/≥14pt粗)与 UI 边界 ≥3:1。实测：dark 13.9:1 · light 14.8:1。 |
| **WCAG 2.2 SC 1.4.4 缩放文字**（AA） | Web 内容 | 文本可放大至 **200%** 不失内容/功能；依赖浏览器/UA 缩放，作者不得阻止。 |
| **WCAG 2.2 SC 1.4.6 增强对比度**（AAA） | Web 内容 | 正文 ≥**7:1**、大字 ≥**4.5:1**。本页双主题已超（13.9/14.8），可作高对比基线。 |
| **WCAG 2.2 SC 1.4.10 回流**（AA） | Web 内容 | 320 CSS px 宽 / 256 CSS px 高（≈400% 缩放）无二维滚动；表格/图形/地图/演示等二维布局例外。 |
| **WCAG 2.2 SC 1.4.11 非文本对比**（AA） | Web 内容 | UI 组件识别/状态、图形对象理解所需部分 ≥**3:1**（不四舍五入）。 |
| **WCAG 2.2 SC 1.4.12 文字间距**（AA） | Web 内容 | 行高 ≥1.5×、段距 ≥2×、字距 ≥0.12×、词距 ≥0.16× 字号，调大不失真。 |
| **WAI-ARIA APG switch** | Web 内容 | `role="switch"` + `aria-checked`；Space/Enter 切换；标签恒定；与 checkbox 区分。 |
| **CSS color-scheme / @media prefers-color-scheme** | Web 内容 | 声明 `dark light`，随系统偏好初值；配 `<meta name="color-scheme">` 与早期脚本防首屏闪烁。 |
| **CSS Color L4 oklch() / light-dark()** | Web 内容 | 感知均匀着色，主题调色板演进方向。 |
| **prefers-reduced-motion** | Web 内容 | 「减少动态」偏好下停用动画/过渡（前庭安全）。 |
| **ISO 9241-303:2011 电子视觉显示人因** | 硬件/人因 | 亮度/对比/眩光控制/减少闪烁/字符高度/图像极性——指导视觉疲劳与舒适度；技术中立、可指导 Web 视觉设计原则。 |
| **IEC 62471 / IEC-TR 62778 蓝光危害** | 硬件（非 Web 内容） | 评 400–500nm 蓝光对视网膜的光生物安全；风险组 **RG0**（免除，10000s 内不伤）/**RG1**（100s）/**RG2**（0.25s）/**RG3**（瞬时）。儿童读写台灯/教室照明要求 RG0。 |

## 三、层归属判定（诚实不冒充）

- **可落地的 Web 内容层**（本仓前端可视化职责）：全部 WCAG 2.2 SC 1.4.x、ARIA switch、color-scheme、oklch、prefers-reduced-motion。
- **硬件/人因层（仅作设计原则参考，不冒充职责）**：ISO 9241-303 的亮度/眩光/闪烁——它约束的是**显示器硬件与工作站**，但「高对比、字符高度、减少闪烁」原则与本页减动效/高对比一致，可借鉴。
- **纯硬件安全标准（明确不属 Web 内容标准）**：IEC 62471/62778 蓝光危害风险组。它是**灯具/LED 背光**的认证门槛，软件暗色模式只是降整体像素亮度、间接减蓝光发射，不构成「护眼」保证。

## 五、诚实边界（关键纠偏）

1. **散光（astigmatism）是「深色模式护眼」的反例**：研究显示散光用户在暗背景+亮字下感知更模糊，亮背景+暗字反而更清晰。故本页**保留浅色主题**为等效选项，不主张暗色「更护眼」。
2. **青光眼/白内障 → 对比敏感度下降 → 高对比需求**（SC 1.4.3/1.4.6）。其临床管理（眼压控制、角膜塑形、手术）**不属** Web 前端标准职责，本仓不越界。
3. **弱视/低视力 ≠ 色盲**：低视力主要靠**放大 + 高对比**（SC 1.4.4/1.4.10/1.4.12），色盲靠**非颜色编码**（SC 1.4.1），两项本页分别有对应落地与标注。
4. **真「护眼」= 符合 ISO 9241 的亮度/对比/眩光控制 + WCAG 对比度 + 支持缩放 + 减少动效/频闪**——皆本页已落地的层；暗色模式仅是其中一项可选手段，不是充分条件。
