## 二、标准清单与量化阈值

### 2.1 屈光（近视 / 远视）· 眼科与器械层（医学/硬件）

| 标准 | 层级 | 关键阈值 / 要点 |
|------|------|----------------|
| **屈光不正 refraction error 分类** | 医学 | 近视 myopia（负球镜，negative sphere, D）、远视 hyperopia（正球镜，positive sphere, D）、散光 astigmatism（柱镜 cylinder + 轴位 axis 0–180°）、老花 presbyopia（add 下加光）。单位：**屈光度 diopter (D)** |
| **验光方法** | 医学 | 客观验光 = autorefractor 电脑验光仪；主观验光 = phoropter 综合验光仪 / trial lens 试镜架。镜片光学功率常规以 **0.25 D** 步进 |
| **ISO 10342** | 硬件（眼科器械） | Ophthalmic instruments — Eye-refractometers：验光仪/电脑验光仪的性能与测试要求 |
| **ISO 8598（ISO 8598-1/-2）** | 硬件（眼科器械） | Ophthalmic instruments — Focimeters：焦度计/查片仪，验证成品镜片球/柱/轴光度，含允差 |
| **ISO 11979** | 硬件（植入器械） | Ophthalmic implants — Intraocular lenses（人工晶状体，1999 发布、2014 修订）：功率允差 ±0.3 D（0–15 D）/ ±0.4 D（15–25 D）/ ±0.5 D（25–30 D）/ ±1.0 D（>30 D） |
| **ANSI Z80.1** | 硬件（处方镜片） | Prescription ophthalmic lenses：球/柱/轴允差、棱镜与基底方向等美国处方镜片要求 |

### 2.2 环境光 / 照度 (lux) · 照明层（硬件/建筑）

| 标准 | 层级 | 关键阈值 / 要点 |
|------|------|----------------|
| **EN 12464-1:2021** | 照明（室内） | 室内工作场所照明：办公室最小平均**维护照度** Em = **500 lx**；均匀度 Uo = Emin/Eavg **≥ 0.60**（精密工作 ≥ 0.70）；统一眩光值 **UGR ≤ 19**（越低越不眩）；显色指数 **Ra ≥ 80**（优 ≥ 90） |
| **EN 12464-2:2014** | 照明（室外） | 室外工作场所照明对应 Em / Uo / GRL / Ra 要求 |
| **ISO/CIE 8995-1:2025** | 照明（室内） | Lighting of work places — Indoor work places：维护照度（maintained illuminance，计及光源衰减与积尘后的平均照度） |
| **CIE S 008 / EN 12665** | 术语 | 照明基础术语定义（Em、Uo、UGR、Ra 等） |
| **CIE S 026** | 人因照明 | Human-centred lighting / 昼夜节律：黑素等效日光照度 **M-EDI**，衔接 WELL 等健康建筑框架 |
| **IES（Illuminating Engineering Society）** | 照明（北美） | 办公室建议 **300–500 lx**（以屏幕为主可接受 300 lx） |
| **照度比与邻近区** | 照明 | 任务区:邻近区 ≥ 0.5× 且 ≥ 100 lx；背景 ≥ 1/3 任务区且 ≥ 50 lx；圆柱照度（人脸识别）办公室 150 lx / Uo ≥ 0.10；维护系数 fm：初始照度 Ei = Em / fm |

### 2.3 光学元件 / 镀膜 · 光学制造层（硬件）

| 标准 | 层级 | 关键阈值 / 要点 |
|------|------|----------------|
| **ISO 10110 系列** | 硬件（光学制图） | Optics and photonics — Preparation of drawings for optical elements and systems：光学元件与系统图样绘制与公差标注的统一语言 |
| **ISO 10110-5:2026** | 硬件 | 表面形状公差：nm 为首选单位（fringe 间距仍可用但须声明基准波长）；覆盖平面/球面/非球面/柱面/复曲面 |
| **ISO 10110-11:2025** | 硬件 | 未注公差（默认值），保证未单独标注的要素不松于标准默认 |
| **ISO 10110 标注法** | 硬件 | 3/A(B/C) 表面形状（球面矢高/不规则/p-v）；4/α 中心偏；5/N×A 表面缺陷面积；λ 圈 功能镀膜（AR 减反 / FI 滤光） |
| **参考波长** | 硬件 | ISO 10110 默认 **546.07 nm**（汞 e 线）；CIE 光度学 **555 nm / 555.017 nm**（见 §2.4） |
| **ISO 9211 系列** | 硬件（光学镀膜） | Optical coatings：ISO 9211-1 术语/分类/光学特性（τ(λ) 透射 / ρ(λ) 反射 / α(λ) 吸收）；ISO 9211-2 描述与应用（AR/FI 等，谱特性先于规格书写）；ISO 9211-3 环境耐久（基于 ISO 9022）；ISO 9211-4 镀膜专项耐久测试 |

### 2.4 CIE 光度学 V(λ) 与光度–辐射量换算 · 计量层（物理）

| 标准/量 | 层级 | 关键阈值 / 要点 |
|------|------|----------------|
| **CIE 1924 V(λ)** | 计量（光度） | 明视觉光谱光视效率函数（标准观察者）：定义在 360–830 nm（1 nm 间隔），峰值 **555 nm**（标准空气 555.017 nm，对应频率 540 THz） |
| **暗视觉 V′(λ) / 中视觉** | 计量 | 暗视觉峰值 ~507 nm；明–暗之间为中视觉 mesopic，CIE 已补定义补充函数 |
| **最大光谱光视效能 Km** | 计量 | **683 lm/W**（540×10¹² Hz，真空 λ=555.017 nm，CIE 1924 值） |
| **换算公式（BIPM）** | 计量 | Φv = Km ∫ Φe,λ(λ)·V(λ) dλ；单色简化 Φv = 683·V(λ)·Φe。1 W@555 nm = 683 lm；650 nm ≈ 73 lm/W；1550 nm = 0 |
| **成对量（辐射↔光度）** | 计量 | radiant flux Φe(W) ↔ luminous flux Φv(lm)；radiant intensity(W/sr) ↔ luminous intensity(cd=lm/sr)；irradiance(W/m²) ↔ illuminance(lux=lm/m²)；radiance(W/m²·sr) ↔ luminance(cd/m²=nit) |
| **职责划分** | 计量 | CIPM 定义光度单位（坎德拉）；CIE 标准化光谱光视效率函数 V(λ)/V′(λ) |

### 2.5 光的波粒二象性 / 量子光学 · 物理基础层（物理）

| 主题 | 层级 | 关键要点 |
|------|------|----------------|
| **发展史** | 物理 | Maxwell 电磁波动理论（Hertz 1880s 验证）→ Planck 1900 能量量子化 hν（黑体辐射，1918 诺奖）→ Einstein 1905 光量子假说解释光电效应（1921 诺奖，Millikan 1915/1916 验证）→ Compton 1923 康普顿散射（1927 诺奖，光子携动量）→ de Broglie 1924 物质波 λ=h/p（Davisson-Germer 1927 电子衍射验证） |
| **波粒二象性** | 物理 | Young 双缝干涉（波动性）↔ 光电效应 / 康普顿散射（粒子性）；同一光子在不同实验配置下呈现波或粒子行为 |
| **光子关系** | 物理 | E = hν，p = h/λ；普朗克常数 h = 6.626×10⁻³⁴ J·s；光速 c = 2.99792458×10⁸ m/s；fλ = c/n_a(λ)（标准空气 n_a ≈ 1.00028） |
| **现代框架** | 物理 | 量子电动力学 QED / 标准模型：光子是规范玻色子（电磁相互作用媒介），零静止质量，是量子场的激发（量子场论语义） |

## 四、本仓相关落点（可呼应的 Web 内容层）

- **环境光 ↔ 暗/亮主题**：EN 12464 / ISO 9241-302（显示工作区照明与亮度）的「环境光下视觉舒适」原则，本仓已通过 concept_gui.html 的**主题开关**落实——用户随系统 `prefers-color-scheme` 或手动选暗/亮，呼应「不同环境光下降低视觉疲劳」。但这是**软件主题适配**，不是 lux 照明工程，不冒充 EN 12464 为本仓职责。
- **圆光术「光」主题 ↔ 物理科普层**：docs/60/61 已把「光/颜色/视觉」作为 concept_gui.html 的视觉范式；本轮查据的 V(λ) 光度学、波粒二象性可在**明确标注为物理参考层**的前提下，作为圆光术概念的可选科普锚点（不冒充 Web 标准）。
- **ISO 9241 人因（已在 docs/60 覆盖）**：高对比、字符高度、减少闪烁是「真护眼」的硬件/人因来源，本仓 Web 层通过对比度达标 + 减动效 + 支持缩放呼应，属已落地层。

## 五、诚实边界（关键纠偏）

1. **本仓是软件（系统优化 / 可视化），不是验光仪、镜片厂、灯具或物理实验室**：屈光度数（ISO 10342/8598/11979）、光学镀膜（ISO 10110/9211）、照度 lux（EN 12464）、波粒二象性均**不属本仓能力**，只作「设计原则参考 + 知识边界澄清」。
2. **近视/远视的「度数」是临床验光产物**：由 ISO 10342/8598 器械与 ISO 11979（IOL）规范约束，本仓**不提供任何视力评估**。
3. **暗色模式 ≠ 照明工程**：EN 12464 的 500 lx / UGR / Ra 是物理空间照明，本仓软件主题切换只是界面呈现，不构成「照明合规」或「护眼保证」；沿用 docs/60 的诚实边界——真护眼 = 高对比 + 支持缩放 + 减少动效/频闪 + 合理亮度，暗色仅是可选手段之一。
4. **科普层不越界**：V(λ)/波粒二象性仅作为圆光术「光」主题的可选科普锚点，明确标为物理参考层，不写入任何 Web 内容标准清单。
