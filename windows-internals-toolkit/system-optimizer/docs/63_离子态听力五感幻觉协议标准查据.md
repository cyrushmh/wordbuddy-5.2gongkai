## 二、标准清单与量化阈值

### 2.1 离子态（物质第四态 · 离子通道）· 物理/生理基底层（参考，无 Web 映射）

> 说明：「离子态协议」严格说并不对应一个命名标准簇。检索「ionization / plasma / 电离 / 等离子」返回的是 IEC 62366-1（医疗器械人因可用性，与"离子"无直接关系，属关键词串扰）与电离辐射剂量学（IEC 62387 / ICRP / IAEA）。本仓语境下应理解为**物理/生理基底**：

| 主题 | 层级 | 关键要点 |
|------|------|----------------|
| **等离子态（物质第四态）** | 物理 | 气体电离后电子与离子分离的状态（astro/plasma physics 基础）。属物理参考层，无 Web 职责映射 |
| **离子通道 ion channels** | 生理 | 所有感觉转导（含下文的听力与幻觉神经基础）的生物物理学前提：机械/声/光/化学刺激经离子通道转为神经电信号。属生理参考层 |
| **IEC 62366-1:2015+A1:2020** | 医疗人因（跨领域） | Medical devices — Usability engineering to safety：use specification → 识别与安全性相关的 UI 特征/已知可预见危险 → 危险相关使用场景 → 形成性/总结性评估。虽为医疗器械标准，其「人因/可用性工程过程」是通用 UX 纪律范本，可作为本仓 UI 安全思维的参考（不冒充医疗职责） |
| **电离辐射安全（相邻参考）** | 物理/安全 | ICRP 出版物、IAEA 基本安全标准、IEC 62387（被动剂量计）管辖电离辐射，与"离子态"字面相邻但主题独立，列此以防误用 |

### 2.2 听力（听觉）· 声学/医疗器械层（医学/硬件）+ Web 内容层（可落地）

| 标准 | 层级 | 关键阈值 / 要点 |
|------|------|----------------|
| **ISO 8253-1:2010** | 临床声学 | Acoustic audiometric test methods — Part 1：纯音气导/骨导听阈测听（125 Hz–8 kHz，步进 5 dB） |
| **ISO 8253-2:2009** | 临床声学 | Part 2：声场测听（free/diffuse/quasi-free field，可扩至 20 Hz–16 kHz） |
| **ISO 8253-3:2022** | 临床声学 | Part 3：言语测听（speech audiometry） |
| **ISO 226** | 心理声学 | Normal equal-loudness-level contours：等响曲线（不同频率达到同等响度所需的声压级），定义响度感知的非线性 |
| **ISO 389 系列** | 临床声学 | Reference zero for audiometers：测听零基准（不同换能器/骨导的 reference equivalent threshold force/levels, RETFL/RETSPL） |
| **ISO 1999:2013** | 职业声学 | Estimation of noise-induced hearing loss：噪声性听损估算（A 计权、暴露年限、年龄修正） |
| **ISO 7029:2017(+Amd1:2024)** | 生理声学 | 随年龄与性别的听阈统计分布（年龄相关性听力下降基线） |
| **IEC 60118 系列** | 硬件（助听器） | Hearing aids：电声性能与测量（含生产特性测量 IEC 60118-7） |
| **IEC 60645 系列** | 硬件（测听设备） | Audiometers：听力计电声要求 |
| **WHO 数据** | 公共卫生 | 全球约 **4.3 亿** 致残性听力损失人群（WHO 口径），是 Web 媒体无障碍的现实需求基数 |
| **⭐ WCAG 2.2 — 时间媒体（1.2.x）** | **Web 内容层** | **可落地**：1.2.1（音/视频-only 文本替代）、1.2.2 Captions 预录(A)、1.2.4 Captions 直播(AA)、1.2.3/1.2.5 Audio Description(A/AA)、1.2.6 Sign Language(AAA)、1.2.9 Audio-only 直播(AAA) —— 给 d/Deaf 与重听用户 |
| **⭐ WCAG 2.2 — 1.4.2 Audio Control (A)** | **Web 内容层** | **可落地**：自动播放且 > 3 秒的音频必须可暂停/停止/独立调音量（独立于系统音量）；直接约束本仓任何自动发声的前端产物 |
| **⭐ WCAG 2.2 — 1.4.7 Low or No Background Audio (AAA)** | **Web 内容层** | **可落地**：预录语音的背景声须低于语音 ≥ **20 dB**，或提供关闭方式；提升听障用户在噪声环境/重听辅助下的可懂度 |

### 2.3 五官五感差异（多感官整合）· 神经科学/人因层（生理）+ Web 内容层（已落地）

| 主题 | 层级 | 关键要点 |
|------|------|----------------|
| **Sensory processing / 多感官整合** | 生理/神经 | 大脑整合视/听/触/嗅/味 + 前庭/本体/内感受为统一知觉；McGurk 效应、腹语效应证明跨模态耦合（Harry McGurk & John MacDonald, Nature 1976） |
| **五感 vs 扩展感官** | 生理 | 经典五感外还有前庭（平衡）、本体（位置）、内感受（内脏）、痛觉、时间感等；"五感"是简化模型 |
| **ISO 9241（人因工学）** | 人因 | Ergonomics of human-system interaction：感知/可辨性相关的人机交互原则，是多感官 Web 设计的上位人因框架 |
| **⭐ WCAG 2.2 — 1.3.3 Sensory Characteristics (A)** | **Web 内容层** | **已落地（docs/61 §五）**：操作指引不得仅依赖形状/颜色/尺寸/位置/声音；须有文本等多通道冗余 |
| **⭐ WCAG 2.2 — 1.4.1 Use of Color (A)** | **Web 内容层** | **已落地（docs/61 §五）**：信息不得仅靠颜色传达（字形○●◆▽ + 形状 + 文本三重区分）；正是"五感差异 → 不能假定人人同色觉"的工程化 |

### 2.4 幻听（听觉幻觉）· 精神/神经分类层（医学）

| 主题 | 层级 | 关键要点 |
|------|------|----------------|
| **ICD-11** | 医学分类 | 幻觉定义为**无相应外界刺激却具真实感**的知觉体验（hallucination in absence of external stimulus with compelling sense of reality）；幻听 auditory/verbal hallucination 最常见于精神病性障碍 |
| **DSM-5** | 医学分类 | 幻觉（含幻听）作为精神病性症状；需排除躯体病/物质/其他精神障碍；急性短暂性精神病性障碍阈值 ≥ 1 天、精神分裂症 ≥ 6 个月 |
| ** tinnitus 与幻听边界** | 医学 | 耳鸣常被视为 elementary auditory hallucination（简单听觉幻觉）；但搏动性耳鸣多为真实血流声，不属幻觉 |
| **Web 关系（非诊断）** | Web 内容层 | 不属 WCAG 诊断条目；但 1.4.2 自动音频控制、避免无预警突发声响，客观上降低对听觉敏感/幻觉倾向用户的诱发与困扰 |

### 2.5 幻视（视觉幻觉）· 精神/神经分类层（医学）+ Web 内容层（可落地）

| 主题 | 层级 | 关键要点 |
|------|------|----------------|
| **ICD-11 / DSM-5** | 医学分类 | 幻视 visual hallucination：无外界视觉刺激却"看见"图像；Charles Bonnet 综合征（视力丧失者的单纯幻视）、催眠/入睡前幻觉等 |
| **⭐ WCAG 2.2 — 2.3.1 Three Flashes or Below Threshold (A)** | **Web 内容层** | **可落地（强相关）**：任何内容在任一 1 秒内的闪烁不得超过 **3 次**（或满足一般闪光阈值）；一般闪光阈值上限 **20.0 cd/m²**，红色闪光阈值更严 **6.0 cd/m²**；为光敏性癫痫（photosensitive epilepsy）患者设防。W3C 工具 PEAT（Photosensitive Epilepsy Analysis Tool）可实测；G19 技术（≤3 闪/秒）是充分条件 |
| **WCAG 2.2 — 2.3.2 Three Flashes (AAA)** | Web 内容层 | 更高要求：完全禁止任何闪烁内容（AAA） |
| **Web 关系** | Web 内容层 | 直接约束本仓任何动效/动画前端产物：docs/61 的 `prefers-reduced-motion` 归零应**扩展**为"不出现 > 3 闪/秒的闪烁"，与 2.3.1 对齐 |

### 2.6 幻触（触觉幻觉）· 精神/神经分类层（医学）

| 主题 | 层级 | 关键要点 |
|------|------|----------------|
| **ICD-11 / DSM-5** | 医学分类 | 幻触 tactile/somatic hallucination：无外界触觉刺激却感到虫爬、电击、身体变形等（常见于可卡因/致幻剂、谵妄、精神分裂症、中枢神经系统病变） |
| **前庭/本体相邻（Web）** | Web 内容层 | 无直接"触觉" WCAG 条目；但 WCAG 2.3.3（Animation from Interactions，已纳入 WCAG 2.2 草案/2.3 家族）约束由用户交互触发的、可引发前庭不适的动画——与"体感/运动"相邻，是幻触之外更贴近前端的体感安全落点 |

## 四、本仓相关落点（Web 内容层）

1. **听力 → 媒体无障碍基线**：若本仓任何前端产物引入音视频或自动播放音频，须满足 1.2.x（字幕/文本替代/音频描述）、1.4.2（>3 秒自动音频可控）、1.4.7（背景声低于语音 20 dB）。当前 `concept_gui.html` / `report_viewer` 无音视频，故本期列为**契约基线**，不强制改造。
2. **五感差异 → 非颜色/多通道编码（已落地）**：docs/61 §五 的「字形○●◆▽ + 形状 + 文本」三重区分正是 1.3.3 / 1.4.1 的工程化，呼应"不能假定人人同色觉/同感官"。
3. **幻视 → 光敏癫痫硬约束（建议）**：在 docs/61 减动效基础上，新增「内容闪烁 ≤ 3 次/秒、满足一般闪光阈值 20 cd/m²（红 6 cd/m²）」的验收项，对齐 WCAG 2.3.1；PEAT 可作验证工具。此为 opt-in 待办。
4. **离子态/IEC 62366-1 → 人因纪律参考**：IEC 62366-1 的「使用规范 → 危险相关使用场景 → 总结性评估」过程，可作为本仓 UI 安全思维的通用范本（不冒充医疗职责）。

## 五、诚实边界（钉死不冒充）

- 离子态（等离子态/离子通道）、听力测听与临床声学（ISO/TC 43 全系）、幻听/幻视/幻触（ICD-11/DSM-5）——一律判为**物理/生理/医学/心理参考层**，只作「设计原则参考 + 知识边界澄清」，**不冒充**为本仓 Web 前端标准或能力，也不在代码层声称具备任何诊断/临床功能。
- 唯一可呼应的 Web 落点 = **听力媒体无障碍（1.2.x/1.4.2/1.4.7）** 与 **幻视↔光敏癫痫（2.3.1）**，二者为本仓前端**应守**的 WCAG 义务，已单列；其余具体医学阈值（听阈 dB、听损估算、幻觉诊断标准）属临床，不冒充。
