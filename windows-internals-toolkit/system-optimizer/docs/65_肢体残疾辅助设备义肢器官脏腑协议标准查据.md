### 2.6 ⭐ Web 内容层可落地项：WCAG 2.2 Operable 原则（服务肢体残疾/精细运动障碍用户）

> 这是本脉标准在本仓的**唯一 Web 落点**。肢体残疾、截肢、肌无力、震颤、腕管、RSI、老龄化精细运动退化等用户，依赖键盘/开关/语音/眼动等替代输入与放大的目标尺寸。WCAG 2.2 Operable（可操作）原则全套如下：

| 条目 | 级别 | 要求（与肢体/运动障碍相关处加粗） |

| **2.1.1 Keyboard** | A | 全部功能可**经键盘接口操作**，无特定按键时限；键盘焦点可见不隐藏 |
| **2.1.2 No Keyboard Trap** | A | 焦点进入某组件后**必须能移出**（模态窗必须可 Esc/焦点环出） |
| **2.1.3 Keyboard (No Exception)** | AAA | 无例外全键盘可达 |
| **2.1.4 Character Key Shortcuts** | A | 单字符快捷键可关闭/重映射/仅焦点激活 |
| **2.2.1 Timing Adjustable** | A | 有时间限制的交互必须可**关闭/调整/延长**（≥ 10 倍，或关闭+20 秒警示） |
| **2.2.2 Pause, Stop, Hide** | A | 移动/闪烁/滚动/自动更新 > 5 秒的内容必须可暂停/停止/隐藏 |

| **2.4.4 Link Purpose (In Context)** | A | 链接/按钮用途可从文本/上下文识别 |

## 四、本仓相关落点（Web 内容层）

1. **唯一 Web 落点 = WCAG 2.2 Operable 原则**：肢体残疾/精细运动障碍用户经键盘、开关、语音等替代输入使用本仓前端产物（`concept_gui.html`、`report_viewer.html` 及未来 Deno 控制台），须满足 2.1.x 键盘可达/无陷阱、2.2.x 时间可调/可暂停、2.4.7 焦点可见、2.5.7 拖拽替代、**2.5.8 目标尺寸 ≥ 24×24 CSS px**。
2. **两 HTML 现状实测（上一轮 Bash 审计）**：`concept_gui.html` 有 `role="switch"`×2、`aria-checked`×4、`<button>`×2、`:focus`×1、`min-width`×1——存在键盘可达的 switch/button，但**缺显式 tabindex 管理、焦点样式不充分、目标尺寸未系统设置**；`report_viewer.html` 仅 `<button>`×5、`min-width`×1。即：契约基线明确，落地存在缺口，列为 docs/66 的改造清单（opt-in，未执行）。
3. **参考层的正确定位**：ISO 9999/ICF 分类、轮椅/建筑/假肢/植入器械的全部量化阈值，作为「本仓服务对象的物理世界约束」的知识旁证而存在；本仓不声称、不实现、不模拟任何医疗器械功能。

## 五、诚实边界（钉死不冒充）

- 肢体残疾辅助设备设施（ISO 9999/7176/10542/10865/16840/11199）、外部设备设施、建筑无障碍（ISO 21542/23599、EN 17210、GB 50763/55019）、义肢矫形（ISO 8549/10328/22523/22675/15032/13405/8551）、器官脏腑相关器械（ISO 14708/5840/22442/7198/7197/14607/14630、IEC 60601/62304、ISO 13485/14971/10993）——一律判为**物理/硬件/医学/工程参考层**，只作「设计原则参考 + 知识边界澄清」，**不冒充**为本仓 Web 前端标准或能力，也不在代码层声称具备任何假肢/矫形/植入/建筑/临床功能。
- 唯一可呼应的 Web 落点 = **WCAG 2.2 Operable 原则**（2.1.x 键盘、2.2.x 时间、2.4.x 焦点导航、2.5.x 输入模态含 2.5.7 拖拽替代与 2.5.8 目标尺寸 ≥ 24×24 CSS px），为本仓前端**应守**义务；docs/66 将其落实为可验收的前端契约（opt-in 待办）。
- 与 docs/62/63 一致：建筑标准的对比度/照度（Michelson ≥ 30%/60%、20–500 lx 分级）与 Web 对比度是**两套互不套用**的度量体系；本仓 Web 侧数字仍沿用 docs/60/61 实测（dark 13.9:1 / light 14.8:1）。
- ISO 9999:2022 明确**排除植入设备**——故「辅助/外部设备」与「植入/器官脏腑器械」按标准原文分界列节（2.1 vs 2.5），不混编。
