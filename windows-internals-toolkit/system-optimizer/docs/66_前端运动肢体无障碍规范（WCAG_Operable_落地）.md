# 66 · 前端运动/肢体无障碍规范（WCAG Operable 落地）

## 二、键盘可达契约（强制，WCAG 2.1.x）

| 项 | 契约 | WCAG |
|----|------|------|
| 全功能键盘化 | 全部功能**必须**可经键盘接口操作，无不可达的纯鼠标/纯触摸交互；原生 `<button>`/`<a>`/`<input>` 默认可达，自定义控件（div/span/SVG 节点）必须补 `tabindex="0"` 与键盘事件 | 2.1.1 Keyboard (A) |
| 无键盘陷阱 | 焦点进入任何组件后**必须**能移出；模态/弹层必须可用 `Esc` 关闭并把焦点**还给触发元素**；SVG 画布内可聚焦节点不得阻断 Tab 序列 | 2.1.2 No Keyboard Trap (A) |
| 单字符快捷键 | 单字符快捷键（如 `1`–`9` 直达概念系统）必须可关闭、可重映射，或仅在焦点位于组件内时激活，避免语音输入用户误触 | 2.1.4 Character Key Shortcuts (A) |
| 激活键 | 自定义控件必须支持 `Enter` 与 `Space` 激活，语义与原生 button 一致（Space 按下立即触发、Enter 抬起触发可按原生语义从简） | 2.1.1 配套 |

范本现状（concept_gui.html）：主题开关与面板开关均为原生 `<button role="switch">`（默认可达、Space/Enter 生效）；缺口：SVG 拓扑图节点为图形元素，交互（如有）未补 `tabindex` 与键盘事件，单字符直达快捷键未见开关。

## 三、时间与动效控制契约（强制，WCAG 2.2.x）

| 项 | 契约 | WCAG |
|----|------|------|
| 时限可调 | 任何时间限制的交互（会话超时、轮播自动切换、定时刷新）必须可**关闭/调整/延长**：关闭优先；若不能关闭，用户可调至 ≥ 默认值 **10 倍**，且到期前 **≥ 20 秒** 警示并可延长 | 2.2.1 Timing Adjustable (A) |
| 暂停/停止/隐藏 | 移动、闪烁、滚动或自动更新的内容（轮播、跑马灯、实时日志流）持续 > **5 秒** 时必须提供暂停/停止/隐藏机制 | 2.2.2 Pause, Stop, Hide (A) |
| 与减动效的边界 | `prefers-reduced-motion`（docs/61 §四）治前庭不适；2.2.2 治**时间控制权**——二者独立卡控，开 reduce 不等于自动获得暂停权 | — |

范本现状：concept_gui.html 无定时器/轮播/自动刷新，2.2.1/2.2.2 **当前自然满足**；新增任何定时交互前必须按本节补控制机制。

## 四、焦点可见与导航契约（强制，WCAG 2.4.x）

| 项 | 契约 | WCAG |
|----|------|------|
| 焦点可见 | 键盘焦点**必须**清晰可见：`:focus-visible` 样式不得移除（禁 `outline:none` 无替代），焦点环与底色对比 ≥ **3:1** | 2.4.7 Focus Visible (AA) |
| 焦点顺序 | Tab 顺序必须符合阅读/操作逻辑，不得用正 `tabindex` 打乱自然序 | 2.4.3 Focus Order (A) |
| 跳过重复块 | 多区块页面提供 skip link 或 ARIA landmark（`nav`/`main`），减少肢体障碍用户无效遍历 | 2.4.1 Bypass Blocks (A) |
| 焦点不被遮挡 | 吸顶栏/模态/浮层不得完全遮挡获焦组件；打开浮层时聚焦其首个可操作元素，关闭时焦点归还 | 2.4.11 Focus Not Obscured (Minimum) (AA, WCAG 2.2 新增) |
| 标签可读 | 控件可访问名称必须包含可见文本（图标按钮必须有 `aria-label`） | 2.5.3 Label in Name (A) / 2.4.4 配套 |

范本现状：concept_gui.html 有 `:focus` 规则 ×1 但覆盖不全（未用 `:focus-visible` 系统兜底）；图标按钮的 `aria-label` 已有（如主题开关）；report_viewer.html 未见焦点样式。

## 五、输入模态与目标尺寸契约（强制，WCAG 2.5.x）

| 项 | 契约 | WCAG |
|----|------|------|
| 指针手势替代 | 多点/路径手势（双指缩放、画手势）必须提供**单指针**替代（按钮/滑块） | 2.5.1 Pointer Gestures (A) |
| 指针取消 | 交互必须在 **pointerup** 时完成（按下仅进入待定态），提供 `pointercancel` 逃生通道——防震颤/误触 | 2.5.2 Pointer Cancellation (A) |
| 运动触发替代 | 摇晃/倾斜触发的功能必须有 UI 替代且可关闭 | 2.5.4 Motion Actuation (A) |
| **拖拽替代** | 一切拖拽操作（画布平移、节点拖动、滑块拖拽）必须提供**单指针、非拖拽**替代（方向按钮、数值输入、点击定位） | **2.5.7 Dragging Movements (AA, WCAG 2.2 新增)** |
| **目标尺寸** | 指针目标（可点击区域）至少 **24 × 24 CSS px**；例外仅限：等价功能可用、行内文本内、用户代理决定、必要呈现。视觉尺寸不足时用透明 padding/`min-width`/`min-height` 扩命中区 | **2.5.8 Target Size (Minimum) (AA, WCAG 2.2 新增)** |

范本现状：concept_gui.html `min-width` 出现 ×1（个别控件），未系统化到全部交互目标；report_viewer.html `min-width` ×1。目标尺寸是两页共同的系统性缺口。

## 八、诚实边界（不冒充，红线）

1. 本规范只覆盖 WCAG 2.2 Operable 原则的 **Web 内容层**义务；假肢矫形结构试验（ISO 10328/22675）、轮椅压力阈值（ISO 16840）、建筑无障碍尺寸（ISO 21542/GB 55019）、植入器械安全（ISO 14708/5840）等均为**参考层**，本仓不实现、不模拟、不声称。
2. 满足 Operable 契约 ≠ 「无障碍完成」：视觉健康（docs/61）、听力媒体（docs/63 的 1.2.x 基线）、认知无障碍（WCAG 2.2 之外的 Understandable 原则）各有其域，不得以一概全。
3. §六差距清单是**如实登记**，不得在文档或代码注释中宣称两 HTML 已「完全无障碍」；补齐前对外表述一律用「基线契约 + 差距待补」。
4. 目标尺寸 24×24 CSS px 是 **CSS px 口径**（非物理像素），高分屏缩放后物理像素更多，契约判定以 CSS px 为准。
5. #598 轮为只读查据与契约沉淀；**#605 轮（2026-10-25）已按 §六清单完成两 HTML 改造并销项**——改造时按 §七逐项验收（静态门禁 + node 语法校验）并全量回归；后续任何新增交互仍按 §七自检。
