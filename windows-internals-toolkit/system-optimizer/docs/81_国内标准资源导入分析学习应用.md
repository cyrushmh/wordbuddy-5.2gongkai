## 二、各源事实核实（逐站只读结论）

### 2.1 官方权威源（SAMR/SAC 体系）

- **openstd + std.samr（链接 1/2/3）**：国家标准全文公开系统 GB 强制 2054 项（非采标 1718 可下载、采标 336 只阅读）、GB/T 推荐 47283 项（非采标 31224 可下载、采标 16059 只题录）、GB/Z 指导 802 项、外文版 2913 项。全国标准信息公共服务平台为总门户：国家标准化 / 行业标准化（**76 行业 · 88751 项**，host `hbba.sacinfo.org.cn`）/ 地方标准化（**49114 项**，host `dbba.sacinfo.org.cn`）/ 团体标准化（`ttbz.org.cn`）/ 国际标准化（ISO/IEC 国内对口）/ 国外标准化（ANSI/CEN/DIN/BSI/SA/NZSO/KATS）。意见征集、标准公告、计划查询、实施反馈、复审公示、专利公示、TC 组织管理一应俱全。**结论**：中国标准体系的权威入口，是 `cnstd` 数据层的主干。
- **hbba（链接 9）**：行业标准信息服务平台，收录 76 个行业大类代号（AQ 安全、BB 包装、DL 电力、GA 公安、HG 化工、JB 机械、JR 金融、JT 交通、JY 教育、SJ 电子、YD 通信、YS 有色、YY 医药、ZY 中医药……），标准发布公告来自民航局/人民银行/工信部/药监局等。
- **htsfwb（链接 7）**：合同示范文本库，近 500 种合同示范文本，每份附风险提示。属「市场行为合规」口径，与 `protec` 的应急/合规原则可结构同构（不新增为概念，仅登记存在性）。

### 2.2 厂商 / 社区规范源

- **modbus.cn（链接 6）**：1011+ 技术资料，Modbus RTU/TCP/ASCII、功能码、寄存器、CRC、MBAP 报文头，在线调试工具，行业方案（智慧农业/能耗监测/楼宇自控）。属工业总线事实标准，对接 `netsys` 传输与可用性域、工业控制链路。
- **mqtt.org.cn（链接 10）**：MQTT 物联网消息传输标准，轻量高效、QoS 0/1/2、TLS/OAuth、双向通信、不可靠网络支持、数百万设备规模。对接 `netsys` 组网与 `protec.access` 接入与链路域。
- **techphant TPUNB（链接 11）**：技象科技 TPUNB（Techphant Ultra-Narrow Band）100% 自主知识产权 LPWAN，152 发明专利/12 实用新型/16 外观/8 软著；产品 TP5803 射频芯片/TP1107 模块/TP2108 网关/TP5600 DTU/TP9102 基站，TPaaS 云平台；参与窄带无线行业标准与国标体系建设。属「中国自主物联网标准实践」样本，与 MQTT/Modbus 同簇登记。

### 2.3 第三方商业 / 分享源

- **spc.org.cn（链接 5）**：中国标准在线服务网，标准有效性批量校验、作废代替查询、采标库、标准英文版、引用查询、计划查询、工程建设/环境标准库，代理 ISO/IEC/KS/BSI/ASTM/ANSI/IEEE/DIN/ASME/ITU 国外标准。**版权与真伪自负**——仅登记服务范围，不提供规避方法。
- **biaozhuns.com（链接 8）**：标准网，自标「免费标准分享、下载网站」，聚合国标（GB/GB-T/GB-Z/GBZ）、行标（JR-T/DL-T/JB-T/HG-T/SY-T/QC-T/JC-T/YS-T）、地标（DBxx-T）、团标（T/）、企标（Q/GDW 国网、Q/CSG 南网、Q/SY 石油、Q/SH 石化）与国际（DIN/JIS/ISO/ASME），时间跨度 1992–2026。**第三方免费聚合，真伪与版权风险由使用者自负**，红线：不提供代查/代下/破解。

### 2.4 科普 / 开源翻译源

- **腾讯云文章（链接 4）**：《探索网络协议的标准化过程与开放标准的重要性》——TCP/IP 标准化史、开放标准（公开/透明/非专利）价值、Java 作为开放标准编程语言（源码基于 ECMA/ISO）。属概念层科普，**非规范源**，不导入为权威标准条目。
- **华为云博客（链接 12）**：《专有协议与标准协议：通信世界的两大支柱》——专有协议（定制/控制/安全/受限）vs 标准协议（ISO/IEEE 开放/互操作/广支持）。观点性科普，与 `netsys` 协议无关、覆盖全 9 系统的叙事一致。
- **gitcode RFC 中文版（链接 13）**：开源项目，~300 份 RFC 中文翻译，涵盖网络协议/程序设计/网络架构；明确「仅供个人学习研究，严禁商业用途」，建议优先参考英文原版。与既有 `rfc_index`（RFC 全量索引）形成「英文权威 + 中文导读」互补，登记为 `rfc_cn_translations`，不替代 `rfc_catalog` 的权威数据。
