### 诚实缺口（needs_action，全部为 SDK/上游约束，非代码缺陷）

1. **`classics-rs` 缺 `aarch64-pc-windows-gnu`**：rustc target-list **不提供**该三元组（仅 `aarch64-pc-windows-gnullvm` 在列，但其 rust-std 组件在本环境大文件传输停滞）。已由 build 脚本注释登记；Windows ARM64 由 **go:windows-arm64** 覆盖（CI 矩阵 + 本地构建）。
2. **`classics-rs` / `classics-ios-mac` 缺 `*-apple-darwin`**：无 macOS SDK，交叉环境不可建；属上游不可能长期缺席。
3. **`classics-ios-mac` / `classics-harmony-app` 需宿主 SDK**：Xcode / DevEco 均不可交叉，CI 需自托管 macOS / HarmonyOS runner（脚本已声明依赖，不假称可建）。

> 以上与 #662 `docs/80` §五 的 `needs_action` 口径一致，不重复登记、不虚构修复。
