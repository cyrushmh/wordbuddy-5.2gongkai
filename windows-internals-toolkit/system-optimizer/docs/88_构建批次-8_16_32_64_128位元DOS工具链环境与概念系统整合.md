## 三、位宽阶梯实测（8/16/32/64/128 全档）

| 档 | 构建 | 产物 | 验证 |
|---|---|---|---|
| 8 位 | `sdcc -mz80 -o hello8.ihx hello8.c` | 358B Intel HEX | hex 内 `jp 0x0100`/`RST 08h`/`jr` 循环（Z80 指纹） |
| 16 位 | `bcc -V -Md -0 -o hello16.com hello16.c` | 228B 无头 COM | `mov ax,42`+`int 21h/20h`；dosbox 实跑 exit 0 |
| 16 位手写链 | `as86 -0` + `ld86 -d` | 64B 裸 COM | **int 21h 建写关文件，宿主机回读 18B 一致（往返闭环）** |
| 32 位 DOS | djgpp as+ld（`-e _start`） | 7628B MZ+COFF go32 | DJ stub 1993-1995；dosbox 实跑 exit 0（DPMI 反射） |
| 32 位宿主 | `gcc -m32` | ELF i386 | 实跑 exit 0 |
| 64 位 | `gcc -m64` | ELF x86-64 | 实跑 stdout + exit 0 |
| 128 位 | `gcc -O2 -msse2` | ELF（仍报 64 位） | `__int128` sizeof=16 + hi/lo 算术；movdqa XMM 往返 1 2 3 4 |

**稳态交互往返实证**：`loop.com`（死循环）dosbox 挂起被 timeout 杀（exit 124）证执行链；`proof4.com` 落盘 `C:\R7.TXT` 宿主机回读证 16 位 ↔ 宿主闭环；`hello32.exe` exit 0 证 32 位 DPMI 可运行。

## 四、工程坑（排查实录，已入账）

1. **COM 基址错位**（本轮最深层 bug）：`ld86 -d` 以 origin 0 产 COM，DOS 把 COM 装在 PSP:0x100；as86 `#label` 立即数汇编期解析且不带重定位——手写汇编须自加 `$100`（nasm `org 0x100` 等价物）。初版 DX 指向 PSP 内部，create 静默失败；用「create + 死循环」探针分离「程序没跑」与「create 失败」后定位。
2. **dosbox `-c` 语义**：`-c "C:"` 换驱对后续命令不生效，须 `C:\` 全路径（`echo > C:\M1.TXT` 探针实证）。
3. **sdcc 4.2**：必须 ANSI C；z80 裸 `__at` 被拒（error 1 + warning 166），须 `__sfr __at`。
4. **bcc 是 K&R C**：`main(void)` 拒收。

## 五、诚实缺口与边界

- **DJGPP GCC 不在 apt**（仅 binutils 侧）、watcom 不可得——32 位 DOS 的 C 编译路径缺位，needs_verify，未从上游下载；
- **8 位运行层**无 Z80 硬件/模拟器（qemu 不可得）——只到编译产物级；
- **「量子架构位宽」不成立**：qubit 无经典位宽、OpenQASM/QIR 无寄存器宽度档；沙箱无量子工具链（qiskit/cirq 不可导入、apt 无候选）——不臆造量子位阶梯，`simd-128` 概念桥接 `quantum:qubit` 标明范式边界；
- **「能量衍射」非存储工程概念**——不臆造映射；真实对应项（电荷保持/易散性、跨设备 I/O 分布、磨损均衡/调度）已实测登记，容器内磨损态与 SMART 不可见（无 smartctl）。
