# 92_补全批次——量子架构多位元寄存器：结合 PiLink 内存交换参数覆盖 8/16/64/128 位元

> 批次定位：接用户指令「结合之前的内存交换参数，就能支持 8_16_64_128 位元支持了」。
> 0031 轮已交付「qudit 单 d 级系统」（d 上限 8、容量 log₂(d) 比特/符号），更早的量子架构基座
> （v0.6.69）已有 **CPU↔闪存 π 链路不间断交换**（PiLink 内存交换参数）。本批把两者接上：
> 用 N 个 d 级 qudit 并联成**多位元寄存器**，经 PiLink 内存交换参数逐 qudit 交换（不物化
> 8^N 联合态），据此覆盖经典位宽 8/16/64/128。

## 一、缺口定位与路线选择

单 qudit 容量有限（d≤8 → ≤3 bit），独立无法覆盖 8/16/64/128 位元；而朴素地把寄存器做成
单一 d^N 密度矩阵在 128 位 → 8^43 ≈ 2^129 维时完全不可行。两条路：

| 路线 | 可行性 | 取舍 |
|---|---|---|
| 单一 huge 密度矩阵（d^N 维） | ❌ | 128 位 → 2^129 维，内存/算力不可行 |
| N 个 qudit 局部态 + PiLink 内存交换 | ✅（采用） | 每个 qudit 维持 d×d 局部态，交换经 π 链路缓冲，状态分块交换而非铺满内存 |

「内存交换参数」即 `native/quantum.py` 的 `PiLink`（CPU↔量子核 π 链路环形缓冲，容量
`ceil(ratio·π)`）。它本就是架构基座「不间断交换」的落点——本批让 qudit 寄存器复用它。

## 二、实现（native/qudit.py 新增 QuditRegister + register_report）

- `SUPPORTED_WIDTHS = (8, 16, 64, 128)`：声明覆盖的经典位宽。
- `QuditRegister(width_bits, d=8, link_ratio=2.0)`：取 d=8（log₂8=3 bit/qudit），
  `n = ceil(位宽/3)` → 8/16/64/128 位元拆成 **3/6/22/43** 个 qudit；总容量 `n·log₂(d)` 比特。
- 每个 qudit 维持自身 d×d 局部密度矩阵（绝不拼 d^N 联合矩阵）；CPU↔量子核每次交换
  （encode/gate/dissipation/measure）经 `PiLink` 记录——`from .quantum import PiLink`（惰性导入，
  无循环依赖：quantum 不依赖 qudit）。
- `apply_gate`（DFT_d/shift/phase）、`apply_dissipation`（T1 γ / T2 λ）、`encode`/`decode`、
  `purity` 均按单 qudit 局部施加。
- `register_report(width, d, gamma)`：位宽分解表 + 内存交换参数（联合态维数如实展示为「不物化」）+ 一个
  qudit 的 log 值交换演示（散逸下漂）+ 链路统计。
- `capabilities()` 增 `register_widths` 与 `register_memory_exchange`；`qudit_probe()` 增
  寄存器自检（分解覆盖名义位宽 + 内存交换记录交换）。

## 三、数值实证（register_report 64，演示 qudit[0]，v=6，γ=0.3）

| 项 | 值 |
|---|---|
| 名义位宽 / 分解 | 64 bit → 22 个 d=8 qudit（总容量 66 bit ≥ 64） |
| 联合态维数 | 8^22 ≈ 7.4×10¹⁹（**不物化为单一矩阵**） |
| 编码 6.0 → 理想解码 | 6.1459 |
| γ=0.3 散逸后解码 | 4.9920（下漂 1.1539） |
| 链路统计 | size=7，写入 2 次（encode + dissipation），FIFO 节流如实 |

128 位元：43 个 d=8 qudit，总容量 129 bit，联合态维数 8^43 ≈ 6.8×10³⁸（同样不物化）。

## 七、诚实边界

- 经典数值模拟 qudit 寄存器，非真实量子硬件；不接硬件、不联网、不宣称量子优势。
- 多位元 = log₂(d) 比特容量（非 d 比特）；不把 d 级系统混同经典 d 位宽。
- **不物化 8^N 联合态**——仅逐 qudit 局部态，寄存器容量为分解后总容量；耗散按单 qudit 局部施加。
- 耗散为单步均匀衰减模型，不建模真实器件 T1/T2 频变、串扰与门误差谱。
