# 93_补全批次——量子架构多位元寄存器级往返与可复现耗散数值实验

> 批次定位：接 0032 轮「qudit 寄存器（结合 PiLink 内存交换参数覆盖 8/16/64/128 位元）」。
> 0032 只交付了 `QuditRegister`（分块局部态 + PiLink 逐交换、不物化 8^N 联合态）与
> `register_report`（单 qudit 演示）。本批补齐**寄存器级多位元往返**与**可复现的耗散数值实验**——
> 让整数值真正跨全部 N 个 qudit 走完「编码→交换→（散逸+测量）→解码」闭环，并诚实量化
> 耗散信道下多位元寄存器的符号误码率（BER）。

## 一、缺口定位

0032 轮留下的真实缺口：

| 缺口 | 现状（0032） | 本批补法 |
|---|---|---|
| 寄存器级往返 | `exchange_integer` 是独立函数、没用 `QuditRegister` 类；值只走单 qudit | 新增 `register_roundtrip`：值→d 进制 digit 跨全 N 个 qudit 编码，经 PiLink 逐交换，可选散逸+测量后解码回整数 |
| 耗散损失量化 | 只有单 qudit `register_report` 演示一组数 | 新增 `register_experiment`：固定位宽扫 γ，可复现地统计平均/最大 BER |
| 单 qudit 测量 | 模块级 `measure(rho, rng)` 存在，但类无方法 | `QuditRegister.measure(qidx, rng)` 投影测量，接 PiLink 记录 |
| 可视化 | 依赖 matplotlib（非核心红线） | `register_experiment_plot` 改**纯标准库 SVG**，零外部依赖 |

## 二、实现（native/qudit.py）

- `register_roundtrip(width_bits, value, d=8, gamma=0.0, lam=0.0, seed=0)`：
  - 值 `v` 按 d 进制拆成 N 个 digit（`v // d^k % d`），逐 qudit 用 `encode_log_amplitudes` 编码
    （μ=log₂(digit)，digit=0 走真空态）——经 PiLink 逐交换（每个 qudit encode+measure 两次，
    `link_writes == 2·n_qudits`）；
  - 可选 `apply_dissipation(γ, λ)` 后做投影测量，解码 `v̂ = Σ digit̂_k · d^k`；
  - 诚实结果：**γ=0 无损全等**（`ber==0.0 && decoded==value`）；**γ>0 下漂**
    （`decoded ≤ value`，BER 随 γ 单调非减）。
- `register_experiment(width_bits, value=0, d=8, gammas=None, seed=0, n_samples=24)`：
  - 固定位宽、固定 seed（`random.Random(seed)`，可复现）；`gammas` 默认 `linspace(0,1,13)`；
  - 每 γ 跑 `n_samples` 次 `register_roundtrip` 统计 `ber_mean` / `ber_max`；
  - 输出按 γ 升序，诚实反映「多位元寄存器在耗散信道下的损失随 γ 单调增大」。
- `register_experiment_plot(width_bits, d, gammas, seed, n_samples, out_path)`：
  - **纯标准库 SVG**（`<svg>` + `<polyline>` + 轴），不引 matplotlib，守住核心 `pure_stdlib` 红线；
  - 画平均 BER 与最大 BER 两条曲线；无 matplotlib 时不静默退化（本实现根本不依赖它）。
- `QuditRegister.measure(qidx, rng)`：单 qudit 投影测量（复用模块级 `measure`），经 PiLink 记录。
- `qudit_probe()` 增 `register_roundtrip_lossless` 自检（γ=0 无损 + PiLink 记录交换）；
  `capabilities` 增 `register_roundtrip` / `register_experiment` / `register_plot` / `measure`。

## 六、诚实边界（四条，沿用并收紧）

1. **多位元=log₂(d) 比特容量**，非 d 比特——不把 d 级系统混同经典 d 位宽。
2. **经典数值模拟**，不接量子硬件、不宣称量子优势；BER 是数值信道模型下的符号误码率估计，
   非真实器件实测。
3. **不物化 8^N 联合态**——仅逐 qudit 局部态，状态经 PiLink 分块交换而非一次性铺满内存。
4. **耗散为单步均匀衰减模型**，不建模真实 T1/T2 频变、串扰与门误差谱；测量为单次投影，
   未做重复读出纠错。SVG 图表为分析辅助，**不替换数值表**。
