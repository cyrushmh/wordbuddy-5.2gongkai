## 二、逐篇分析（学习点 + 应用评估）

**① GitHub 网址改几个字母看源码**
- 学习点：代码托管平台的 URL 结构即导航 API（tree/blob/blame/commit/raw 等路径段互换），
  是**只读代码阅读**的通用技巧——与本项目「只读登记、不接入、构建期实测」的方法学同构。
- 应用评估：可作为 `apilab`/`plang` 工程方法学的学习注脚；属**元技能**，不构成实体概念，
  不回填。

**② GitHub 电子书索引库**
- 学习点：开源社区的资源聚合/索引实践（单一仓库索引多来源）。
- 应用评估：与本项目「只读层 + 官方源域名核查 + needs_verify 挂牌」的资源治理思路相通；
  但该索引库真伪、覆盖度需深核，**标 needs_verify**，不回填。

**③ Sniffnet（网络流量观测）**
- 学习点：跨平台 GUI 网络流量监测，按远程主机/协议可视化「谁在用网」——是 `netsys`
  网络观测能力的**用户端友好化**范例。
- 应用评估：`netsys` 现有 network/osi/netauth/dhcp/nat/edge 模块，但**无「主机侧流量
  观测/诊断」concept**；Sniffnet 可作为该方向的**候选 counterpart**。需进 APP 深核其
  协议覆盖（TCP/UDP/ICMP 分层、远程聚合）是否值得回填一个 `traffic-observer` 概念。

**④ AV2 视频编码**
- 学习点：新一代免版税视频编码（AOMedia 体系，继 AV1），标称压缩效率较 AV1 +~30%。
- 应用评估：`sciences` 八轴（材料/热力学/气候/环境/物理/化学/生物/方法论）**无媒体编码/
  信息论压缩**概念；属信息论应用层。可作为 `sciences` 的**候选扩展方向**（信息熵/率失真），
  但标 needs_verify（AV2 标准化状态、+30% 口径需核实），不臆造。

**⑤ OnAir SDR（软件无线电）**
- 学习点：一套 SDR 软件接收 158 种信号，含 FM 与 DTMB（数字电视地面广播）实测。
- 应用评估：`baigong`（匠作/工器）域无无线电/S 软件定义无线电 concept；SDR 是**硬件+
  开源软件栈**的匠作范例。候选 counterpart，但需深核信号清单与 DTMB 解调实现，标
  needs_verify，不回填。

**⑥ Anthropic knowledge-work-plug（开源）**
- 学习点：大厂把「知识工作」能力以插件/开源形式释放，呼应 AI 工具链的工程化。
- 应用评估：`apilab`/`plang` 域无「知识工作插件」concept；与本项目「AI 工具链/plang 161 条
  实测」可对照。候选 counterpart，需深核其架构（是否 MCP/插件协议），标 needs_verify。

**⑦ 免费 PS/Word/PDF 替代套件**
- 学习点：民间团队以免费软件复刻商业办公三件套（图像/文字/版式），呼应「可替代、可审计」
  的工器取向。
- 应用评估：`baigong`（匠作工具）域无办公套件 concept；可作为「可审计开源替代」的学习注脚，
  不回填。

**⑧ CN-Language 中文编程语言（解析器）**
- 学习点：中文编程语言项目连载至第 149 篇，本篇讲「解析器（parser）」实现——是编译器
  前端（词法/语法分析）的中文语境落地。
- 应用评估：`plang` 域有编程语言/编译相关条目（161 条实测），但**无中文特定编程语言
  concept**、无「解析器」专题；CN-Language 是真实连载项目，**候选 counterpart**。需深核
  其语言设计（是否中文关键字/中文 AST/自举）与成熟度，标 needs_verify，不臆造回填。

**⑨ SteamVR 2.18（串流/稳定性）**
- 学习点：VR 运行时迭代（串流稳定性、特定头显 Frame 改进）——是 VR/串流工程的版本演进范例。
- 应用评估：`baigong` 域无 VR/串流 concept；候选 counterpart，需深核其串流协议（Encode/
  Decode 时延、丢帧策略），标 needs_verify，不回填。

## 三、跨篇学习（与本项目纪律的同构）

- **开源优先 + 只读核实**：9 篇里有 6 篇（①GitHub 技巧 ②电子书索引 ③Sniffnet ⑥Anthropic
  ⑦免费套件 ⑧CN-Language）本质都是「开源生态的可得性/可审计性」——与本项目
  「只读登记、官方源域名核查、needs_verify 不臆造」的价值取向同构。
- **用户端友好化是落地关键**：Sniffnet（③）、免费套件（⑦）、SteamVR（⑨）都是把底层能力
  做成可用用户端的范例——呼应 `zhuangzi`（南华用户端人体工程学）「以使用者意图为宗师」。
- **方法学 > 实体**：①GitHub URL 技巧属元技能、不应成概念；这与本项目「不把方法当概念堆砌」
  的克制一致。
