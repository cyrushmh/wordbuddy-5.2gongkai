## 二、实现（native/qudit.py）

- `dimension_profile(width_bits, d=8)`：W 位经典整数 → N 个 d 级 qudit 的维度画像。
  - `n_qudits = ⌈W / log₂(d)⌉`；`total_capacity = N·log₂(d) ≥ W`；
  - **升维比** `bits_per_carrier = log₂(d)`（每 qudit 承载的经典比特，即「升维」后每符号维数）；
  - **降维比** `reduction_factor = W / N ≤ bits_per_carrier`（ceil 余量使实际每符号摊到的比特 ≤ 容量）；
  - **联合态维数** `joint_dimension = d**N`——仅作诚实声明，**绝不物化**。
- `elevate_bits(value, n_qudits, d)`：精确离散升维——整数按 base-d 按位展开成 N 个符号（高位在前）。
  这是「低维位串 → 高维符号」的同构：W 个比特被重新表达为 N 个 d 级 qudit。
- `reduce_bits(digits, d)`：精确降维——base-d 解码回整数，是 `elevate_bits` 的同构逆。
  **R∘E = I**：`reduce_bits(elevate_bits(v)) == v`（γ=0 严格成立）。
- `bit_convert(value, width_bits, d=8, gamma=0.0, lam=0.0, seed=0)`：端到端封装。
  - γ=λ=0：**精确离散升维↔降维同构，严格无损**（`decoded==value`、`ber==0`、`lossless=True`）；
  - γ>0：每符号 |dig> 纯态经同位能级散逸（T1 γ / T2 λ）+ 测量塌缩，诚实量化符号损失
    （解码不高于原值、`ber≥0`），与 `register_roundtrip` 同口径；
  - 返回画像指标（capacity_bits / bits_per_carrier / reduction_factor / joint_dimension）+ `lossless` 标志。
- `bit_convert_table(widths=None, d=8)`：8/16/64/128 全位宽维度画像表（CLI `--table` 用）。
- `capabilities` 增 `bit_conversion: True`；`qudit_probe` 增 `dim_reduce_elevate_invertible` /
  `dim_profile_invariant` 自检并纳入 `all_pass`。

## 三、CLI 接入

- `quantum bitconv [width] [value] [gamma] [d]`：打印升维/降维维数画像（升维比 / 降维比 / 总容量 /
  余量 / 联合态维数）+ 输入值的升维 digit、降维 digit、解码值与 BER、`R∘E==I` 标志；
  `width∈SUPPORTED_WIDTHS`、`d∈[2, MAX_D]`、值域越界诚实拒绝。
- `quantum bitconv --table`：打印 8/16/64/128 全宽维度画像表（含联合态维数，标注「不物化」）。
- `quantum` 子命令 `choices` 增 `"bitconv"`；`--table` 标志同步；帮助文本同步。

## 七、诚实边界（五条，沿用并补一条）

1. **多位元=log₂(d) 比特容量**，非 d 比特——不把 d 级系统混同经典 d 位宽。
2. **经典数值模拟**，不接量子硬件、不宣称量子优势；BER 是数值信道模型下的符号误码率估计，非真实器件实测。
3. **不物化 d**N 联合态**——仅逐 qudit 局部态，状态经 PiLink 分块交换而非一次性铺满内存。
4. **耗散为单步均匀衰减模型**，不建模真实 T1/T2 频变、串扰与门误差谱；测量为单次投影，未做重复读出纠错。
5. **降维升维的精确部分是同构无损**（R∘E=I），无信息增益；`joint_dimension` 仅声明维数规模、绝不物化；
   不把「升维」说成信息压缩或量子优势来源。
