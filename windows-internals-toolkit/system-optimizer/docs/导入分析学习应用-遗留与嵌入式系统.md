# 导入分析学习应用 · 遗留 / 嵌入式 / 兼容层（DOS 3.1 等 · busybox · dosbox）

> v0.6.21 · 把「DOS 3.1 等遗留 DOS 环境」「busybox 嵌入式用户态」「dosbox DOS 模拟兼容层」
> 吸收为**只读诊断**能力，并**嵌入整体系统**（经 sysmap 关联图与既有模块产生「你中有我」关系）。

## 0. 本轮指令与设计原则

- 用户指令：「利用现有资源和连接器尽量全选；引入 dos3.1 等、busybox、dosbox 嵌入整体系统；继续。」
- **利用现有资源和连接器尽量全选**：本模块不重新发明轮子——
  - 复用 `common.run` / `shutil.which` 等既有只读资源；
  - 关联既有连接器：OpenWrt（busybox 即其根用户态）、Proton（dosbox 同属兼容层）、
    WSL（旧环境迁移桥）、livemedia（DOS 启动盘复用其 mtools/syslinux 工具链）；
  - 合法 DOS 镜像取回可走第三方 **CDN·P2P 开关 aria2**（见 `thirdparty` 引用），仅限本人有权获取的资源。
- **嵌入整体系统**：三项经 `sysmap` 关联图与 18 个子系统编排在一起，不是孤岛。

## 1. 三项技术坐标（仅把「该看什么」钉死，绝不执行写/运行）

### 1.1 DOS 3.1 等（遗留 DOS 环境）
- **MS-DOS 3.1**（1984/85）：x86 实模式 · FAT12 软盘 360KB/1.2MB · COM/EXE ·
  CONFIG.SYS / AUTOEXEC.BAT · HIMEM.SYS / EMM386.EXE · INT 21h(系统)/10h(视频)/13h(磁盘)/16h(键盘)。
- **现代开源替代 FreeDOS 1.4**（2025-04，Jim Hall 发起，MIT/GPL，兼容 MS-DOS）。
- **DOSEMU2**（GPL-2.0）：Linux 上**近原生**跑实模式 DOS 的 DPMI 虚拟机（非模拟）。
- **与 livemedia 共生**：制作 DOS 启动软盘需 mtools + syslinux + FreeDOS 基础文件，
  复用 v0.6.20 已覆盖的 ISO/软盘工具链知识（你中有我）。

### 1.2 busybox（嵌入式用户态「瑞士军刀」）
- 单文件多调用二进制，把 ls/cp/cat/mount/ps 等浓缩进一个可执行；广泛用于
  嵌入式路由器（**OpenWrt 即以 busybox 为根用户态**）、安装器 initrd/initramfs、
  Docker 极简镜像。
- 嵌入式上下文判定（只读）：OpenWrt 标记(`/etc/openwrt_release`)、Docker(`/.dockerenv`)、
  `/bin`·`/sbin` 软链到 busybox（initramfs/嵌入式根）。
- **连接器联动**：busybox ↔ OpenWrt（路由器根用户态）、busybox ↔ livemedia（initramfs 早期用户态）。

### 1.3 dosbox（DOS 模拟兼容层）
- SDL 实现的 x86 实模式模拟器，把 8086/286/386 **动态重编译**，在现 OS 上跑老 DOS 游戏/程序。
- 核心概念：**CPU core**（simple/normal/dynamic/auto）、**cycles**（fixed/max 调速）、**mount C <dir>**。
- 衍生生态：Em-DOSBox（Emscripten→浏览器）、DOSBox-X（更准、支持 Win9x）、DBGL 前端。
- **连接器联动**：dosbox ↔ proton（兼容层，一个 DOS 一个 Windows）、dosbox ↔ wsl（旧环境迁移桥）。

## 2. 落地的只读诊断能力

| 模块 | 报告函数 | 只读核验内容 |
|---|---|---|
| `native/legacy.py` | `dos_report()` | FreeDOS/DOSEMU2 存在性 · 制作 DOS 启动盘前提(mtools/syslinux) · DOS 3.1 知识坐标 |
| | `busybox_report()` | busybox 版本 · applet 数 · 嵌入式上下文(OpenWrt/Docker/initramfs) |
| | `dosbox_report()` | dosbox 版本 · 配置(~/.dosbox/*.conf) · core/cycles/mount 概念 |
| | `legacy_report()` | 三项聚合 + 嵌入整体系统结论 |
| | `capabilities_report()` | 能力自检 + 红线声明 |

- 任务（`tasks/legacy.py`）：`legacy_dos` / `legacy_busybox` / `legacy_dosbox`
  （platform=any · category=maintenance · risk=low）。
- 接入：`registry.py` 注册 · `cli.py`（`legacy` 子命令）· `gui.py`（「遗留/嵌入式」按钮 + 只读窗口）·
  `sysmap.py`（3 个 PROBES + 4 条 RELATIONS，嵌入 18 子系统总览）· `native/__init__.py`（docstring + `__all__`）。
- 版本号统一：0.6.20 → **0.6.21**（3 处：`__init__.py` / `pyproject.toml` / `main.go`）。

## 3. 红线（与全项目一致，本层更严）
