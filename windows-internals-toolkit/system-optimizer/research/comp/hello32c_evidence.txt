----- 9. 诚实边界 -----
· dosbox 0.74-3 的 dpmi=true 不被 DJGPP 12.2 go32 桩接受，须自带 CWSDPMI.EXE(csdpmi7b)。
· DOS 批处理 + CWSDPMI 下 %ERRORLEVEL% 不 propagate 且 dosbox 退出挂起(rc=124)，
  故进程完成证据取直跑 dosbox rc=0 + 两文件写全(fclose 成功)；退出码面不做伪证。
· 程序 return 0 → DJGPP exit → int 21h AH=4Ch 经 DPMI 反射（与上批手写 hello32.exe 同路径）。
